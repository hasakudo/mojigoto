      PCの作品をDriveへ取り込む

      PCに保存している作品を使う場合

      1. 原稿と .mojigoto が入った作品フォルダ全体を選ぶ
      2. ファイル数を確認して「Driveへ取り込む」を押す
      3. 完了後、HOMEへ戻って作品を開く

      ここに作品フォルダを1つドロップ

      取り込む作品フォルダとファイル数を確認してください。Driveへの取り込みは、次の「Driveへ取り込む」で開始します。

      取り込み前の確認

      同じ名前のフォルダがあっても、別の新しいフォルダへ取り込みます。名前は取り込み後にも変更できます。

      書き出し専用など、作品編集に使わないフォルダだけを選んで除外できます。

      .vscodeの設定・ノート画像・履歴は保持します。
      原稿や.mojigoto／.vscodeフォルダは除外をしません。.git／node_modules／.local-config／.env設定ファイルは取り込まず、元のPCフォルダは変更しません。

      取り込みの進行状況

      Driveに新しいフォルダを作りますが、元のPCフォルダはそのまま残ります。
      空フォルダと_WORKは取り込みません。G:では各作品の原稿フォルダを直接参照します。
      Multiモードフォルダの読み込みはファイル数により時間がかかる場合があります。

      許可済み作品へ切り替える・登録を復元する

      PCから取り込んだ作品も、既存作品を許可して登録した作品も選べます。
      Singleは使いたい作品フォルダを、Multiは作品が並ぶ親フォルダを選んでください。

      許可済みの項目だけを読み込みます。取り込みが途中で止まった作品の不足ファイルは復元できません。
      PCで新しく追加したファイル／フォルダには別途許可が必要です。

      Drive上の取り込み先ルートフォルダの名前は変更できます。
      名前の表示が古いときや登録が見つからないときは、名前を変えた同じフォルダを選んで登録を復元してください。

      再取り込みではありません。PC側の保存先も確認してください。
      manuscriptや.mojigotoなど内部のフォルダ名を自由に変更する手順ではありません。

      Driveにある既存作品をそのまま使う

      複製を作らず、今のDriveフォルダを使いたい場合はこちらを選んでください。

      Webで使うファイル／フォルダを手動で選択・許可する必要があります。

      作品フォルダを選ぶだけでは、配下のファイル／フォルダまで許可されません。

      Google Driveの権限の仕様により「もじごとWebで作成した項目、または選択して許可した項目」だけを操作できます。

      親フォルダとその配下すべてを一括で許可することはできません。
      各フォルダ内では複数選択できますが、子フォルダの配下も別途選択・許可が必要です。

      中断すると手動登録の続きは残ります。
      リセットはこの画面の選択だけを消し、Driveのデータ・許可・登録済み作品は変更しません。

      以前の版で移行した場合
      構想メモやバックアップが直下に残っていないか、中身を確認してから整理してください。

      VS Codeでも同じ作品を使うには

      2. VS CodeでそのDriveフォルダを開き、編集先をここに統一する。PC取り込みでは.vscodeの設定を保持します。
        もじごとの対応版では、元PCの保存先設定を取り込み先へ更新します。
        Multiでは作品が並ぶ親フォルダを開き、使いたい作品へ切り替えます

      ファイル／フォルダを許可するについて
      更新したファイルの許可について
      1. 許可済みファイルの編集には再許可は不要です。
      2. 新しく作った項目の場所がわからない場合は、各フォルダの中身をまとめて選び直してください。
      3. 許可済みの項目を再選択しても、ファイルは複製・上書きされません。
      1. 選択待ちフォルダを開き、その中のファイル・子フォルダをすべて選ぶ
      2. 選択を確定すると、次のフォルダの中身を案内します

      .mojigoto、原稿、ノート、設定、バックアップを含めてください。
      未許可の項目や選択漏れはWeb版から確認できません。
      すべてを選択：PCは Ctrl+A、Macは Command+A

      「1」の次を選ぶ
      次の操作で配下のファイルやフォルダを選ぶフォルダであり、フォルダ自体を選び直す案内ではありません。
      残りの数には表示のフォルダも含まれます。未許可の項目を検出した数ではありません。

      フォルダが空なのでスキップ
      plots や references などにJSONファイルがまだ作られておらず、中身が空の場合に使います。
      Googleの選択画面で、他のファイルや子フォルダもないことを確認してから進んでください。

      このフォルダをWebでは使わない
      Export Rootなどの書き出し専用フォルダは、中身があっても配下の選択を省略できます。
      Drive上に残るため、VS Codeでは引き続き使えます。

      原稿／.mojigoto／ノート／設定／バックアップには使わないでください。
      登録完了後、同一ブラウザでは次回の追加許可でも省略します。

      必要になったら、許可画面の「Webの許可手順から除外したフォルダ」で除外を解除してください。

      ファイル／フォルダを許可するへ戻る
      追加許可と、Webで使わない項目

      追加許可はVS CodeでDriveに新規作成・再作成したファイル／フォルダごとに必要です。

      すでに許可された同じファイルの内容を更新する場合の再許可は不要です。

      Webで作成した項目はアプリの許可対象になります。

      • 原稿：新しく作った各ファイルとフォルダ。
      • プロット／資料：新しく作ったノート画面ごとのJSONファイル。
      • 構想メモ：concept-memos.jsonという1ファイル。
        許可済みならメモが0件から1件に増えても、その件数変化による追加許可は不要です。
        ファイル自体を初めて作った／作り直した場合は許可します。
      • 履歴・執筆記録・索引・集計：その機能で使う新しいファイルも許可します。

      Webで使わない書き出し専用フォルダ
      .vscode、_WORK、trash、templatesなどは、配下の許可を省略できる候補です。

      原稿・作品設定・ノート・構想メモの保存先は省略しないでください。
      履歴をWebで使うならbackupsも許可してください。

      現行Webはノートの画像ファイルを表示しません。
      note-imagesの許可を省略できますが、画像ファイルはVS Codeで使います。
      PCから取り込みでは省く必要はありません。

      接続許可を取り消したい方へ

      Googleアカウントの接続設定で、もじごとへの接続許可を取り消せます。
      Driveの作品データは削除されません。

      登録済みのフォルダを削除・変更した場合

      誤って削除した場合は、まずGoogle Driveのゴミ箱から元のフォルダを復元してください。
      別のフォルダを使う場合や復元できない場合は、Web側の登録を解除してPCから取り込む。
      またはDriveの別フォルダを登録してください。

      このブラウザの登録・途中の手順・除外設定・対象フォルダの閲覧履歴を消します。
      Driveのデータ・Googleへの接続許可・他のクラウドの登録は変更しません。

      MOJIGOTO GUIDE

      もじごとガイド

      ログインとクラウド接続、作品データの取り扱いについてご案内します。

      1ログインできるアカウント

      利用申請時に登録したメールアドレスのMicrosoftアカウントまたはGoogleアカウントでログインしてください。登録されていないメールアドレスでは利用できません。

      2クラウドへ接続する

      ログイン後、原稿を保存しているOneDriveまたはGoogle Drive、あるいはDropboxへ接続し、作品フォルダを選びます。

      ログインとクラウド接続は別の操作です。クラウドへの接続時に、ファイルを読み書きするための許可画面が表示されます。

      3読み込むデータについて

      作品データは選択したクラウドドライブからブラウザへ読み込みます。原稿・ノート・構想メモなどの作品ファイルは、もじごとのサーバーへアップロードまたは保存されません。

      4データと安全について

      クラウド接続用のアクセストークンはブラウザ内で扱います。共用端末では、利用後にクラウド接続の解除ともじごとからのログアウトを行ってください。

      5VS Code版との互換性

      このWebアプリはVS Code拡張機能「もじごと」の補助アプリです。データ形式や同期仕様が変わる更新では、VS Code版とWeb版の両方を対応するバージョンへ更新してください。

      スマホやタブレットから、いつもの作品フォルダを確認・編集するための簡易ガイドです。

      1クラウドへ接続する（OneDrive・Google Drive・Dropbox）

      もじごとへのログインとクラウド接続は別の操作です。HOMEで作品を保存しているサービスを選び、ファイルへのアクセスを許可してください。

      OneDrive

      「OneDriveに接続」を押してMicrosoftの画面でアクセスを許可し、アプリ内のフォルダ一覧から作品フォルダを選びます。

      Google Drive

      「Google Driveに接続」から専用の登録ページへ進みます。
      初回はパソコンでの操作をおすすめします。

      1. 専用ページでGoogle Driveに接続します。
      2. 「PCの作品をDriveへ取り込む」から、パソコンの作品フォルダを選んで取り込みます。
      3. 取り込みが終わったらHOMEへ戻り、作品を開きます。

      すでにDriveにある作品を使う場合

      「Driveにある既存作品をそのまま使う」を選び、各フォルダの中のファイル・子フォルダを手動で許可します。

      Google Driveの権限の仕様により「もじごとWebで作成した項目、または選択して許可した項目」だけを操作できます。

      VS Codeで扱うフォルダ

      パソコン版Google Driveで同期した、もじごとWebと同じ作品フォルダをVS Codeで開いてください。
      許可済みファイルの編集だけなら再許可は不要です。

      VS Codeで新規作成・削除して作り直した場合

      新しく作った項目や、削除して作り直した項目は、HOMEの「登録済み作品の追加ファイルを許可」から許可してください。
      追加した場所がわからない場合は、各フォルダの中身をまとめて選び直せます。

      2作品を開く

      作品一覧では状態での絞り込み、更新日時・タイトル・文字数・ノート数での並び替えができます。集計を有効にすると文字数とノート数も表示します。

      作品を選ぶと、上部タブまたは画面下のメニューから原稿・プロット・資料・構想メモ・作品設定を切り替えられます。

      章フォルダがある場合は、原稿一覧のパンくずから前の階層へ戻れます。

      原稿編集画面の歯車メニューから「ノート参照」を開くと、原稿を編集したままプロット・資料を選んで確認できます。広い画面では右側、狭い画面では開閉できるパネルとして表示します。「数え方」も同じ歯車メニューにあります。

      同じ作品内では前回開いていた一覧や編集画面を保持します。再読み込み時も、可能な範囲で前回の画面を開き直します。

      3入力補助を使う

      原稿・ノート・構想メモの「入力補助」から、字下げ、記号、ルビ、傍点を挿入できます。原稿をスマートフォンで編集するときは、入力補助を編集ヘッダー直下へ表示します。

      「記号」サブメニューには大・中・小見出し（# ・## ・### ）と、二重かぎ括弧・隅付き括弧・二重山括弧があります。

      文字列を選択してから括弧・ルビ・傍点を押すと、選択範囲へ記法を付けます。「解除」は、選択範囲に付いた括弧・ルビ・傍点の記法を外します。

      接続設定ではサイトと入力欄の文字サイズを変更できます。原稿のプレビューは横書き／縦書きを選べ、縦書きでは1行の文字数を画面に合わせる自動表示、文字数指定、行間変更を利用できます。

      4保存とVS Code同期
      • 「保存」で現在の内容を接続中のクラウドドライブへ保存します。
      • キーボードでは Ctrl + S（Macは Command + S）で、開いている原稿・ノート・構想メモ・作品設定を保存できます。
      • 自動保存を有効にすると、入力後しばらくして保存します。
      • VS Code側で変更した内容は、Web側が外部更新を確認して読み直します。
      • 両方で変更された場合は自動上書きせず、競合として確認を求めます。

      バックアップ履歴の対象は、原稿フォルダ内の .txt／.md、各プロット／資料ノート、作品の構想メモです。ノートはファイル単位、構想メモは作品内の全メモをまとめて比較・復元します。作品設定、呼び名一覧、画像などは対象外です。

      原稿の歯車メニューにある「バックアップ」、またはノート／構想メモ編集画面の「履歴」から、手動バックアップ、比較、復元、履歴の保護ができます。

      比較では変更行を色分けし、「前の差分」「次の差分」で長文の変更箇所を順に確認できます。
      自動バックアップの間隔は履歴画面で変更・無効化できます。復元前の内容は設定にかかわらず履歴へ保存します。
      履歴は対象ごとに50件まで、自動履歴は90日で整理されますが、保護した履歴は残ります。

      保存先は作品内の .mojigoto/backups で、VS Code版と共有されます。作品全体の保全には、作品フォルダのコピーやクラウドストレージの履歴も併用してください。

      5ショートカットキー

      Ctrl + S（Macは Command + S）で、現在編集中の内容を保存します。

      Escで、開いているポップアップ・メニュー・目次を閉じます。

      Alt + 1〜6（Macは Option + 1〜6）で作品内の画面を切り替えます。

      1. 作品一覧
      2. 原稿
      3. プロット
      4. 資料
      5. 構想メモ
      6. 作品設定

      スマホやタブレットでは、画面上部の「保存」ボタンまたは自動保存を使用してください。

      6困ったとき
      • 作品が見つからない：選択フォルダ内の .mojigoto または原稿フォルダを確認します。
      • 更新が見えない：保存状態を確認してから再読み込みします。
      • 読み込みに失敗する・読み込みが終わらない：下の手順で再読み込みをお試しください。
      • 競合が出た：残したい内容を確認してから、最新版の再読み込みまたは保存を選びます。
      1. 未保存の編集がある場合は、先に保存してください。保存できない場合は、入力内容をコピーして別の場所へ控えてください。
      2. インターネット接続を確認し、設定の「再読み込み」を開いて「再読み込み」を押します。
      3. 改善しない場合は、同じ場所の「アプリのキャッシュを削除して再読み込み」を押します。インストールしたアプリでも利用できます。画面用のキャッシュだけを削除し、作品データ・ログイン情報・履歴・ピン留め・設定は残ります。
      4. ドライブとの通信エラーが続く場合は、接続状態を確認し、必要に応じてドライブへ再接続してください。
      7データと安全について

      作品データは接続したクラウドドライブに保存され、もじごとのサーバーには保存されません。共用端末では、利用後にクラウド接続の解除ともじごとからのログアウトを行ってください。

      8VS Code版との互換性

      このWebアプリは、VS Code拡張機能「もじごと」の補助アプリです。両方が同じ作品データを安全に扱えるよう、対応するバージョンを使用してください。

      VS Code版の更新でデータ形式や同期仕様が変わった場合は、Web版も対応版への更新が必要です。片方だけ古い状態では、読み込み・保存・同期が正しく動作しないことがあります。

      9メールアドレスの取り扱い

      登録メールアドレスは、ログイン・招待の管理、申込や問い合わせへの対応、運営からの連絡に使用します。

      管理画面ではメールアドレスを伏せ字で表示し、利用者IDで管理します。全文を表示する機能はありません。本人確認に必要な元のアドレスは、サーバーの登録情報に保持します。

      利用・解除申込や問い合わせの内容は、受付メールと運営への通知にも含まれます。メッセージには必要のない個人情報を記載しないでください。
