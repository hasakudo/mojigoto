4. 作品データの取扱い

  1. 原稿、ノート、構想メモ、作品設定等は、利用者が選択したOneDrive・Google Drive・Dropboxに保存されます。
  2. 本サービスのWebサーバーは、作品データを恒常的に受信・保存する中継先として使用しません。作品データはブラウザから各クラウドサービスのAPIへ直接送受信されます。
  3. 表示・編集のため、作品データは利用中のブラウザのメモリ上で処理されます。一覧表示の高速化に必要な作品名・ファイル名・フォルダ識別情報、更新日時、文字数、作品設定の要約、OneDriveの差分確認用の追跡情報等が端末内へキャッシュされる場合があります。
  4. バックアップ履歴は、原稿・プロット／資料ノート・構想メモを対象に接続先クラウドへ保存します。作品設定・呼び名一覧・画像などの履歴は対象外です。バックアップは保持ルールに従って整理・削除される場合があります。
  5. SNS向けの画像・投稿文はブラウザ内で生成します。保存・コピー・共有は利用者の操作で行い、共有する場合は選択した共有先へ画像や投稿文を渡します。
  6. 共有端末では、利用後に本サービスからログアウトしてクラウド接続を解除し、必要に応じてブラウザのサイトデータを削除してください。ログアウトや接続解除だけでは、端末内の設定・閲覧履歴・キャッシュ等がすべて消えるとは限りません。

OneDriveへの接続と情報の取扱い

OneDriveへの接続は、利用者がMicrosoftの認可画面で許可した場合に開始します。ファイル操作に Files.ReadWrite を使用し、サインインした利用者のファイルの読み取り・作成・更新・削除を行う権限を要求します。作品データの処理は選択した作品フォルダとその配下を対象とし、ブラウザとMicrosoft Graph APIの間で直接送受信します。作品データやOneDriveの接続トークンを運営サーバーへ送信・保存しません。

アクセストークンと、取得した場合の更新トークンはブラウザのSession Storageに保持します。更新トークンは接続を維持するため、Microsoftの認証サービスへ送信して新しいアクセストークンを取得します。アプリで接続を解除すると、このブラウザの接続トークンを削除します。Microsoft側のアクセス許可を取り消す場合は、Microsoftアカウントのアプリへの許可管理から操作してください。接続解除でOneDriveの作品データは削除されません。

5. Googleユーザーデータの限定的利用

  1. Google Driveへの接続は、利用者が「Google Driveに接続」を選び、Googleの認可画面で許可した場合に限り開始します。
  2. Google Driveのアクセス権限は drive.file に限定します。もじごとWebで作成した項目と、利用者がGoogle Pickerで選択して許可した項目を対象とし、登録した作品内の原稿、ノート、構想メモ、作品設定およびバックアップの表示・作成・更新・移動・削除に使用します。バックアップは保持ルールに従い整理・削除される場合があります。
  3. 既存作品は、親フォルダの選択だけでは配下の項目を許可できません。利用者が各フォルダ内で必要な項目を選択して許可します。許可済み項目の編集には再許可は不要ですが、VS Code等で新しく作成した項目や削除して作り直した項目には追加許可が必要です。書き出し専用フォルダ等の除外は許可手順を省略する設定であり、Driveのデータやすでに与えたアクセス許可を変更しません。
  4. PCの作品取り込みでは、利用者が選択したフォルダ内のファイルをブラウザで読み取り、利用者のDriveに作成する新しいフォルダへ直接送信します。元のPCフォルダは変更せず、空フォルダは取り込みません。中断・失敗時に作成済みのフォルダ・ファイルは自動削除せず、利用者のDriveに残ります。
  5. Google Driveのアクセストークンは利用中のブラウザのSession Storageにのみ保持し、本サービスの運営サーバーへ送信または保存しません。作品データもブラウザとGoogle Drive APIの間で直接送受信されます。
  6. Googleユーザーデータを広告への利用、販売、信用評価、または一般化されたAI・機械学習モデルの学習に使用しません。
  7. 法令上必要な場合、セキュリティ上の調査、利用者が明示的に依頼したサポート、または利用者の同意がある場合を除き、人がGoogleユーザーデータを閲覧しません。
  8. Google APIから受け取った情報の使用および他のアプリへの転送は、限定的使用要件を含むGoogle API Services User Data Policyに準拠します。

Google Driveとの接続を解除すると、ブラウザに保持したアクセストークンを削除し、Googleへ失効を要求します。利用者はGoogleアカウントの接続済みアプリ管理からもアクセス権を取り消せます。接続解除後もGoogle Drive上の作品データは自動削除されず、利用者が引き続き管理できます。

「作品フォルダの登録を解除」は、このブラウザの作品フォルダ登録・途中の登録手順・除外設定・対象フォルダの閲覧履歴とGoogle Driveの一覧表示用キャッシュを削除します。Googleへの接続許可やDriveの作品データは変更しません。「選択・登録手順をリセット」は途中の手順だけを消し、登録済み作品は残します。ブラウザの保存情報を消去した場合や別のブラウザ・端末を使用する場合は、フォルダの登録・除外設定を改めて行う必要があります。

Dropboxへの接続と情報の取扱い

Dropboxへの接続も利用者が認可画面で許可した場合に限り開始します。既存作品フォルダを扱うためDropbox全体への読み書き権限を要求しますが、作品データの処理は選択した作品フォルダとその配下を対象とします。アクセストークンはブラウザのSession Storageだけに保持し、作品データはブラウザとDropbox APIの間で直接送受信します。運営サーバーへトークンや作品データを送信・保存しません。接続解除時はブラウザの接続情報を削除し、Dropboxへトークンの失効を要求します。Dropbox上の作品データは自動削除しません。

サーバーアクセスログさくらインターネットのサーバー設定に基づき12か月間

上記期間の経過後、対象情報は削除または個人を識別できない状態へ処理します。ただし、法令対応、不正利用調査または紛争対応に必要な情報は、その目的に必要な期間に限り保存する場合があります。

11. Cookie・端末保存情報

本サービスは、ログイン維持とセキュリティのために必須Cookieを使用し、表示設定・接続先・キャッシュ等をLocal StorageまたはSession Storageへ保存します。起動・更新時の読み込みに備え、アプリの画面やプログラム等をブラウザのCache Storageへ保存します。現時点では、行動ターゲティング広告または広告目的の第三者Cookieを使用しません。

将来、第三者の広告配信サービス等を導入する場合は、導入前に本ポリシーを見直し、外部へ送信される情報、送信先、利用目的および停止方法等を本サービス上で案内します。
