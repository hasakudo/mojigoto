# 5-D3 Dashboardの構想メモ・共通TODO・表示設定（2026-10-22）

## 変更

ハイライト分析は利用者確認済み。構想メモ・共通TODOと表示設定の5操作を`dashboard-memo-actions.js`へ分離した。

- 構想メモ内TODOの完了切替、共通TODOの完了切替、個別メモのDashboard表示切替、構想メモ編集を開く操作、種類別の表示設定を移動。
- メッセージ名・入口を維持。各操作本体は着手前と一致し、データストア・通知・設定保存・再描画を既存の境界経由で呼び出す。
- 保存先は操作時にホストの解決関数で決める。作品切替・単独モードの判定を複製せず、執筆メモのコピー先の解決とも共有する。
- 対象のないTODO／メモでは保存・通知しない。TODOの本文や他メモ・未知項目を保持し、保存後に通知・再描画する。
- 表示設定のWorkspace保存、グラフ方式のdaily／totalへの限定、設定キーが未知の場合の既存動作を維持。
- 構想TODOの失敗は従来どおりログ、共通TODOと個別表示切替の失敗はログとエラー表示。保存後の通知・再描画失敗では保存内容を戻さない。構想TODOの再描画は従来どおり待機せず、共通TODOと個別表示切替は待機する。
- 画面構成・データ形式・保存／競合制御の方式・集計計算・Web配布コードは変更しない。版は1.0.68。インストール・公開・コミットは行わない。
