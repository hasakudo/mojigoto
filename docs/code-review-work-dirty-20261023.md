# 6-D2 作品切り替え前の未保存原稿処理（2026-10-23）

## 変更

候補探索は利用者確認済み。対象パスの比較と未保存原稿の処理を`work-switch-dirty-guard.js`へ分離した。

- `_normPath`、`_isUnderDir`、`guardDirtyDocsBeforeSwitch`を移動。既存サービスの公開API・呼出箇所を維持し、共有のフォルダ確保を注入する。
- 対象ルート配下の未保存file文書だけの抽出、ファイルごとの保存／破棄切替、一括指定、取消、通常保存とリンク元保存の選択、実体パス解決、相対パスを保持した書込み、保存／破棄後に閉じる順序を維持。
- 点検で、通常保存の`save()`がfalseを返し未保存が残った場合でも切り替えが進むことを再現。分離とは別の修正として、保存結果がfalse、または保存後もisDirtyがtrueの場合はエラー表示し切り替えを中止する。残りの文書処理・参照先変更へ進まない。
- 上記の中止条件以外は関数本体を維持。既存の閉じる操作の例外抑止や、実体保存・保存失敗の扱いは変更しない。切り替え処理本体、候補探索、参照先更新、切替後の画面更新はサービスに残す。
- 保存形式・Web・集計・イベント登録は未変更。版は1.0.68。インストール・公開・コミットは行わない。

## 確認と次の段階

未保存原稿がある状態での作品切り替えについて、通常保存・リンク元保存・破棄・取消、必要なら複数ファイルの個別指定を確認対象とする。通常保存が取り消された場合は作品が切り替わらないことも対象。

確認後は切替実行と切替後の更新処理を点検し、監視・起動接続へ進む。後続のノート名・大分類名の保存／出典反映、構想復元タブ名、一覧からの反映入口、検索／置換えは別予定として保持する。
