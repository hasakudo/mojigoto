# 6-D3 作品切替コマンドと後処理（2026-10-23）

## 変更

未保存原稿の処理と表示順は利用者確認済み。作品切替コマンドの実行・切替後処理を`work-switch-command.js`へ分離した。

- `switchWorkAndRestart`のコマンド本体を移動。登録と依存の既定値は`work-commands.js`に残し、登録順・コンテキスト購読も維持。
- 参照先の切り替えは既存の`switchWorkImpl`に委譲。候補探索・未保存確認を分離済みで、残る本体は切替順序を担うため今回は追加分割しない。
- 切替後は、作品名表示→名前補完→旧原稿タブ終了→集計差分リセット→共有執筆記録取込→通知→サーバー再起動またはping→必要ならプレビュー同期→再集計予約→Dashboard更新→ツリー更新→サイドバー表示の順を維持。
- キャンセルでは後処理を実行しない。プレビュー同期とサイドバー表示の例外抑止、その他の失敗の伝播、再起動OFF・プレビューOFF・省略可能な依存、処理時のプレビュー状態参照を維持。
- コマンド本体は改行・インデントを除き一致。新しい通知・確認・登録は追加しない。保存形式・Web・集計計算は未変更。版は1.0.68。インストール・公開・コミットは行わない。
