# Webガイドの簡潔化・表示・入口整理（2026-10-29）

## 方針と結果

利用者から、文章量・説明過多を減らし、公開前の旧バージョンの説明を省き、スタイルと重複・入口を整理する依頼。通常の操作を短い手順にし、補足は必要時に展開する形へ変更した。単独ガイドのmain内の総文字数は、HTMLタグ・空白を除く同条件で8,132→2,944文字（約64％減）。折りたたみ内も含む比較であり、単に隠しただけの削減ではない。

Web1.0.261／シェルv306／CSS1.0.202。単独ガイドのCSS・JSも1.0.261へ更新。拡張機能は変更なし。本番・テスト環境への反映、コミット、公開は未実施。

## 内容の整理

- ログイン前は「ログイン・クラウド接続・作品選択」の3ステップ。
- 通常ガイドは目的別の10項目。保存・同期の中へ集中していた検索・置換、メモ連携、バックアップを独立させた。初期表示はすべて閉じ、はじめる／検索・置換／保存・同期／困ったときの4つの近道を置いた。
- 検索・置換は共通の3手順へまとめ、原稿1ファイル・ノート1件・構想メモ全体の範囲を短いカードで区別。取り消しと保護対象は補足へ。
- 開発途中の従来設定・旧版の条件分岐・版ごとの差・移行説明を一般ガイドから削除。Google Driveの登録手順の繰り返しは専用登録ページへ集約。
- 未保存・反映中・競合時の対処、構想メモの復元が全メモ対象である点、Google Driveの追加許可など、操作判断に必要な情報は残した。
- メールアドレスの管理内部仕様などを省き、利用者が使う問い合わせ・利用解除・プライバシーポリシーへの入口へ整理。

## 表示・入口・保守

余白と行間を取り、見出し・短い手順・要点のボックス・補足を分けた。小さい画面では近道と範囲カードを折り返す。画面内のヘッダーと閉じる操作、単独ページの追従ヘッダーを維持する。

アプリ内から開く入口は画面内ガイドへ統一。操作中のガイドは対象の項目だけを開き、一般入口は見出し一覧から始める。「別タブでガイドを開く」は明示リンクとして残した。ガイド内のリンクはアプリのURLや編集画面を変えずに移動する。

scripts/web-guide-content.cjsを共通原稿とし、scripts/sync-web-guide.cjsからindex.htmlとguide.htmlの静的本文を生成する。実行時の追加通信に依存しない。更新後はnode scripts/sync-web-guide.cjsを実行し、--checkで一致を確認する。既存のguide-saving／guide-auto-reflect／各検索／旧section番号のリンク先は維持。

## 反映後の確認事項

1. 通常のガイド入口で見出し一覧が表示され、読みたい項目を開閉できる。
2. 歯車や検索画面のガイドから目的の項目が開き、ガイドを閉じると編集へ戻れる。
3. 小さい画面と普段の文字サイズで、見出し・近道・本文・閉じるボタンが読みやすい。
4. 説明が足りない場面や、まだ長く感じる項目を確認。別タブのガイド、Google Driveの登録ページ、問い合わせへのリンクも確認する。
