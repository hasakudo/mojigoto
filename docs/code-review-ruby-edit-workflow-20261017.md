## 入力

新規グループは従来どおり原稿内の「よみ」を選択。新規単一・既存の簡易編集はVS Codeの小さな入力欄で完結する。既存の読みを初期表示し、単一は `レイ/オン/テール/王国` の1欄で入力する。単一の複数組をまとめて直すときは、対応する記法の範囲全体を選択する。

グループ→単一の変更では、複数字の読みを自動分配しない。元の読みを案内し、必要な個数の区切りで指定してもらう。親文字1字なら既知の対応を引き継ぐ。単一→グループでは入力済みの読みを順に連結して表示する。

半角 `/` は区切り、`\/` は読みの中の `/`、`\\` は読みの中のバックスラッシュを表す。区切りと文字の往復処理を、簡易入力とパネルで共通化した。空欄は該当する字にルビを付けず、全欄空欄や個数の不一致・記法を壊す文字は停止する。原稿へ保存する記法に新しい区切りは追加しない。

既存ルビを値の変更なしで確定したときは、元の省略記法等をそのまま保持し、編集を発行しない。複数範囲は入力を全て終えた後に版と元文字列を再確認して1回の編集／Undo単位で適用する。途中の取消では先行書込みしない。原稿の変更・閉鎖・入力不正・編集失敗でも古い位置へ書き込まない。

## パネル

- 種類は「グループ」「単一」を並べたラジオボタン。
- 単一は文字ごとの入力欄から、順番のラベル付きの1入力欄へ変更。`/` 区切りの個数に不一致があれば理由を表示して適用を止める。表示例と原稿に入る記法は引き続き表示。
- 開いた時と種類を変えた時は入力欄へフォーカスして値を選択する。
- 適用ボタンを取消より先のTab順にした。1対象の入力欄からTab1回で適用へ移動。入力欄のEnter、またはCtrl/Cmd+Enterで適用でき、Escで取り消す。
- IME入力中・keyCode229・変換確定直後200ms・キーリピートのEnterでは適用しない。適用中は追加入力と連打を止め、失敗時は入力を残して再操作できる。原稿変更時も入力を残してコピーできる状態で停止。
