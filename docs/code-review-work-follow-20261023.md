# 6-D4 作品名変更への追従・切替時のタブ終了（2026-10-23）

## 変更

切り替えと後処理は利用者確認済み。残る作品フォルダ名変更への追従とタブ終了を点検した。

- 名前変更イベントの対象判定、work.json更新、現在作品・原稿参照先への追従を`work-folder-rename.js`へ分離。イベント登録は従来の呼出元に残し、サービスの公開APIを維持。
- タブ終了は短い共有処理のためサービスに維持。Tab APIと表示エディターへのフォールバック、例外抑止の動作を維持。
- 点検で、作品フォルダ名に追従する設定の再構築が、状態・複数ジャンル・その他の未列挙項目を落とすことを再現。既存設定を展開してから従来の正規化と名前更新を適用し、これらの項目を保持するよう修正。
- Windowsではタブ終了の単純なパス前方一致が大文字小文字を区別して対象を見逃すことを再現。既存のプラットフォーム対応の`_isUnderDir`を共有し、Tab APIとフォールバックの両経路を修正。似た名前の別フォルダは対象にしない。
- 上記修正以外は追従処理本体・対象条件・更新順と失敗時の扱いを維持。設定保存がfalseでも後続する既存動作など、別の挙動変更は加えない。設定の追加項目保持によりJSONのキー順が変わる場合がある。
- 保存形式・Web・集計計算・監視登録は未変更。版は1.0.68。インストール・公開・コミットは行わない。
