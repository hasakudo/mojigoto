# 構想メモの個別自動反映設定への入口（2026-10-26）

## 報告と確認範囲

利用者から、構想メモの自動反映をONにして保存しても反映されず、手動反映は動くと報告を受領した。追加確認で、表示箇所はSOURCE欄の「未反映の変更」だと回答があった。

コード上は、歯車の端末・ブラウザ側許可に加え、作品データのsource.autoSyncToNoteItemがONであることを要する。ノートからの新規リンクでは文書の既定値を引き継ぎ、個別OFFになる場合がある。一方、Webにはその個別値を確認・変更する操作がなかった。

検証用データで、端末側ON・個別OFFなら構想メモ本体だけが保存され、項目メモへ反映されない条件を再現した。利用者の実作品・個別フラグは直接読んでおらず、この条件が実データでも原因だったとは断定していない。既存のOFFを無視する変更は行わず、停止理由と設定入口を補った。

## 変更

- SOURCE欄に「このメモを項目メモへ自動反映」を追加。既存のsource.autoSyncToNoteItemを表示し、変更すると構想メモの下書きとして扱い、通常の保存で作品データへ保存する。
- SOURCE欄に端末側OFF・このメモのOFFの理由と、ONにする操作を表示する。両方がONなら保存後に自動反映する旨と、両側変更時は停止する旨を表示する。
- メモを開いたとき、個別設定変更時、歯車の方向別設定変更時に表示を更新する。
- 個別設定をONにして保存すると、既存の保存・同期判定を通して反映する。sourceなしのメモに出典を作らず、他メモの設定や明示的OFFを一括変更しない。
- 保存・反映ガイドに、歯車の端末側許可とSOURCE欄の作品データ側設定の違いを追記した。

同期方向・同期指紋・版を条件とした保存・競合時の停止・手動反映の仕様は変更していない。
