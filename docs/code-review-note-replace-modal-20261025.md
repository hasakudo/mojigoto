# ノート置換のモーダル表示（2026-10-25）

## 変更

7-A・7-Bの置換動作は利用者確認済み。開閉式だと編集・プレビューを押し下げて候補の表示範囲が小さいため、利用者の提案に従い表示をモーダルへ変更。

- 通常検索の「置換…」ボタンから、画面高を使うネイティブ`dialog`を開く。ノートの作業領域の外へ配置し、開閉しても背面の編集・プレビュー領域を押し下げない。
- モーダル内に検索文字と置換文字、対象条件を表示。検索文字は通常検索へ同期し、候補のフィールドへ移動できる状態を保つ。
- 上部タイトル／閉じる、中央の条件・候補を含むスクロール領域、下部の適用・取り消し・ページ操作に分ける。狭幅では入力欄を縦に並べ、下部操作は折り返す。
- Escと閉じるボタンはモーダルだけを閉じ、通常検索の文字を消さない。条件・置換文字・選択・ページを保持し、変更がなければ再度開いて続けられる。元データや検索条件が変わった場合の候補再計算は維持する。
- 候補の場所ボタンはモーダルを閉じて編集欄へジャンプする。閉じた項目メモを開き、一致範囲を選択する動作を維持。
- Tab／Shift+Tabをモーダル内で循環。Ctrl/Cmd+Fはモーダル内の検索欄へ移動する。候補再描画でフォーカス対象がなくなった場合もモーダル内へ戻す。IME変換中のEscで背面の検索を解除しない。
- Ctrl/Cmd+Sは既存のノート保存を使う。置換・取り消し・保存・ルビ保護・同期・競合保護のロジックは変更しない。ガイドの操作案内も更新。
- 版は1.0.68。インストール・公開・コミットは行わない。
