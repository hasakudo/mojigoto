# 縦書き書き出しの章切り替え・A4プレビュー（2026-10-19）

章別原稿書き出しの追補。最初の選択章しか見られなかった本文プレビューを章セレクトで切り替え、簡易印刷にもA4紙面のプレビューを追加した。

## 操作と対象

- 簡易印刷の「A4プレビューを見る」で、通常は設定中のA4縦／横、2ページ面付けはA4横の紙面を表示。実寸優先の既存プレビューも維持する。
- 章別書き出しではプレビュー内に「プレビューする章」を表示。書き出し対象として選択した章だけを候補とし、「章なし」も選べる。確認する章の変更で書き出す章は変えない。全体を1ファイルにする場合は全体のプレビューを表示する。
- 簡易プレビューと実際のHTML印刷は改ページ処理・印刷の文字サイズ・行送り・余白のCSSを共用。プレビューのみA4寸法の紙面枠を付け、画面幅と高さに合わせて縮小する。出力HTMLに紙面枠やプレビュー専用設定は付けない。
- 生成要求に番号を付け、続けて章を変更したときや閉じた後の古い結果を破棄。入力エラーも処理し、読み込み表示を残さない。
- README・拡張内ガイド・変更履歴を更新。拡張版は1.0.68を維持し、Web配布ソースは変更しない。
