## 変更と理由

- `web/index.html`：既存の歯車4か所に「接続設定」を追加。設定ダイアログと対応付けるaria-controls／aria-haspopupを付けた。ガイドには本文用のスクロール領域を追加。
- `web/app.mjs`：既存の設定表示処理をopenConnectionSettingsへまとめ、従来の入口と歯車から共用。開く際に歯車を閉じ、テーマ・文字サイズを現在値へ合わせる。編集データ、保存基準、dirty、画面経路を変更しない。実際の接続解除・再読み込みにある既存の未保存確認は維持する。
- `web/styles.css`：ガイドの外側と本文の二重スクロールを解消。ヘッダーと本文を縦に配置し、本文だけをスクロールする。狭幅用の古い負のマージンも解除した。ほかのダイアログのスクロール方式は変更していない。
- `web/guide.html`／`guide.css`：ガイド専用のクラスで横方向のoverflowをclipへ変更。bodyがスクロールしない別のスクロールコンテナになり、既存のstickyヘッダーが追従しない状態を解消した。狭幅ではヘッダーの折返しを許容する。
- `web/guide.mjs`／`guide.css`：ヘッダー実測高をアンカー移動時の余白に使う。文字拡大・幅変更・ヘッダーの折返しを反映し、見出しが隠れないようにした。
- 更新読込：本体・起動復旧ビルド1.0.209、共通CSS1.0.183、ガイドCSS1.0.158／JS1.0.157、Service Workerシェルv254。独立ガイドの共通CSS参照も現行に合わせた。拡張機能の版1.0.68は変更していない。
