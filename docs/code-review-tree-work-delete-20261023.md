# 6-C3b 作品全体のOSごみ箱移動（2026-10-23）

## 変更

もじごと内のゴミ箱操作は利用者確認済み。作品全体をOSのごみ箱へ移す処理を`work-tree-work-delete-actions.js`へ分離した。

- `deleteWork`の操作本体と、その専用の`movePathToSystemTrash`を移動。改行・インデントを除き着手前と本体が一致する。
- コマンド登録は元ホスト・同じ順序・コンテキスト購読に残す。通常タブの終了は既存共有処理を注入し、ノート・構想メモ・作品設定の終了も既存の画面管理へ委譲する。
- Single・対象なし・View連携中の拒否、作品名補完、確認取消、false／trueの戻り値を維持する。
- 確認→通常タブ終了→OSプロセス完了→関連Webview3種類の並列終了→ツリー更新→通知の順序を維持。OSプロセスの起動失敗／異常終了、画面終了や更新の失敗は既存の例外通知へ渡し、新たな巻き戻しは追加しない。
- PowerShellの引数・単一引用符エスケープ・SendToRecycleBin指定と、Windows以外の未対応エラーを維持。OS呼出手段の置換は行わない。
- もじごと内のゴミ箱、保存形式・Web・集計計算は未変更。版は1.0.68。インストール・公開・コミットは行わない。
