# バックアップ最終実機確認

2026-10-13追補：以下の構成表は以前の確認記録であり、今回の修正後の実機確認結果ではない。今回のコード・自動テストと次の実機手順は [バックアップ・執筆記録の点検](code-review-stage1-backup-writing-safety-20261013.md) を参照する。

Google DriveのWebでは未許可の履歴を検出できないため、索引の再構築はVS Codeで行う。以下の手順6をGoogle DriveのWebで行う必要はない。新規・再作成された索引と履歴は同期後に追加許可する。

## 対象

- 原稿: .txt / .md ファイル単位
- ノート: plots/*.json / references/*.json の各ファイル単位
- 構想メモ: concept-memos.json 全体
- 対象外: 作品設定、呼び名一覧、画像、テンプレート

保存先は各作品の .mojigoto/backups です。VS Code版とWeb版は同じ index.json と snapshots/*.json を使用します。

各構成で原稿・ノート・構想メモをそれぞれ確認します。

1. 内容を保存し、設定した間隔後の保存で自動履歴が増えることを確認する。
2. 「履歴」から手動バックアップを作成する。
3. 内容を変更し、履歴との比較で差分が表示されることを確認する。
4. 履歴を復元し、復元直前の内容も履歴に残ることを確認する。
5. 履歴を保護し、再度開いても保護状態が残ることを確認する。
6. index.json を別名へ退避してから履歴を開き、残存スナップショットから索引が再生成されることを確認する。
7. VS Codeで作った履歴をWebで、Webで作った履歴をVS Codeで表示・復元できることを確認する。

index.json の退避確認では削除せず、同じフォルダ内で一時的に名前を変えます。確認後、再生成された索引と退避ファイルを比較してから不要な方を整理します。
