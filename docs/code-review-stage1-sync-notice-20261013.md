# 相互反映の通知・ノートのエラー表示（2026-10-13）

利用者から手動・自動の相互保存に問題がないとの実機確認を受領した。追加報告は、ノートの手動反映完了が通知されない、保存中の追加入力時に出るエラーがすぐ消える、構想側の保存通知から反映成功を判断できない、の3点。

## 修正

- ノートの `conceptMemoCreatedFromNoteItem` 受信処理で、未定義のpayloadを参照して同期基準の更新と通知が止まっていた。受信内容を取得して処理するよう修正した。既存メモへの反映は「構想メモへ反映しました。」、新規作成は「構想メモを作成しました。」を表示し、後続のノート保存通知で反映通知を消さない。
- ノートのエラー通知は自動で消さず、「閉じる」を押すまで表示する。通常の保存通知や別操作の通知で上書きしない。閉じるボタンと文字の選択を可能にし、エラーはalertとして読み上げ対象にする。通常の成功通知は従来通り1.8秒で消す。
- 構想の手動反映は「項目メモへ反映しました。」を直ちに表示し、後続保存は「項目メモへ反映し、構想メモを保存しました。」を表示する。
- 構想の自動反映では、実際に更新した項目数と同期エラー数を保存結果へ渡す。項目の反映があれば「項目メモへ反映し、自動保存しました。」等を表示する。反映がない通常保存では従来の保存通知を維持する。一部が失敗した場合は、構想本体の保存成功と反映／同期情報保存の未完了を分けてエラー通知する。
- 保存結果の返答には、その保存のデータを使用し、後続の保存が進んでも別の保存結果を混ぜない。

保存中の追加入力で報告されたエラーの全文は未確認。今回の対応はエラーを読めるようにする表示修正であり、その保存失敗原因が解消したとは扱わない。表示された内容をもとに切り分ける。
