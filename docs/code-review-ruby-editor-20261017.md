# ルビの種類・文字ごとの編集と新規挿入の既定（2026-10-17）

## 今回の結果

[長いルビの設計](code-review-long-ruby-design-20261017.md)の第2単位として、原稿の右クリック／Alt+Rから「ルビを挿入／編集」を開く機能を実装した。グループ・単一を選び、表示例と生成する記法を確認して適用できる。これは編集操作の追加であり、縦書きプレビュー・簡易通常／二面・実寸優先の字送りと最終配置の改善は次の単位。

- グループ：`｜東京《とうきょう》`。
- 単一：`｜東《とう》｜京《きょう》`。読みのほか、当て字・漢字・英字・記号も保持する。
- グループから単一へは自動分配せず、元の注釈を横に表示して文字ごとの入力を求める。親文字1字だけなら既存の対応を引き継ぐ。
- 単一の空欄はその文字にルビを付けない。全欄空欄では適用せず、ルビを全て外すときは既存の解除コマンドを使う。
- 単一からグループへは、入力済みの注釈を順番どおり連結する。グループへ戻して変更していない場合、単一の対応も再表示できる。
- 新規の既定は `mojigoto.rubyDefaultMode` の `group`（初期値）／`mono`。VS Codeのユーザー／ワークスペース設定の通常の優先順を使う。既存の原稿を設定だけで変更しない。記号は既存の `mojigoto.rubyPipeStyle` を新規に適用し、既存の明示記法は先頭の記号を優先する。

この画面はVS Code原稿向け。ノート・構想メモWebview内の既存入力補助バーは変更していない。

## 対象・保存・終了の扱い

既存ルビ内のカーソルや記法の途中選択は、その組全体へ対象を広げる。連続する単一ルビの全体を選べば、まとめてグループへ変えられる。複数選択もまとめて編集でき、同じ組への重複カーソルは一つにする。重なる選択は停止する。

改行、傍点とルビの混在、未完の記号を含む選択は停止する。親文字はIntl.Segmenterの表示文字単位で分け、サロゲートペア・結合文字・異体字セレクタを途中で切らない。ルビ文字列の改行と記法を壊す `| ｜ 《 》` は受け付けず、長さ3～4文字を上限として切り捨てない。

開いただけ・入力中・取消では原稿を変更しない。適用は1回のTextEditor.editにまとめ、Undoも1回で戻す。既存記法を変更せず適用した場合は書き直さない。設定への入口はVS Code設定を開くだけで、自動で設定を書き換えない。

対象はホストが保持し、Webviewから送られた親文字・範囲を採用しない。原稿のversionと対象範囲の元文字列を適用直前に照合する。原稿の変更・閉鎖・適用失敗では入力画面に理由を保持し、最新の原稿から開き直す。適用中の連打は重ねない。同じ文書の編集パネルは再利用する。パネルの終了時は文書監視と受信処理を解除する。入力をWebview stateやファイルへ新しく永続化しない。

HTML／表示例はtextContentとDOM要素で作り、入力をHTMLとして挿入しない。CSPはnonce付きのスクリプトとスタイルだけを許可し、ローカルファイルやネットワークの読込は不要。
