## 2. ガイドで優先して訂正・追記する箇所

### 優先1：現在の動作と異なる説明

1. **自動保存**：「作品設定」「プロット・資料ノート」「構想メモ」にある「入力した内容は自動保存されません」と、「困ったとき」にある「ノート、構想メモ、作品設定は自動保存ではありません」を訂正する。
   - 現行設定は `mojigoto.webviewAutoSaveEnabled` が既定true、`mojigoto.webviewAutoSaveDelaySeconds` が既定0.8秒。
   - 自動保存ONの表示、手動保存も使えること、OFFなら手動保存が必要なことを記す。
   - 原稿本文のVS Code標準Auto Saveとは設定が別であることを明記する。
2. **構想メモの操作場所**：ガイドの「本文コピー」「項目メモへ反映」「ノートを開く」は「︙」前提の説明。v1.0.7のメタデータ欄への集約と現行UIに合わせて、入口を再確認して差し替える。
3. **Sheetsの認可説明**：ガイドは未確認アプリ警告からの操作を常設手順として載せている。既存HOW TO更新原稿は2026-09-24の検証で警告が出ず、通常の権限確認を案内する方針。公開手順は更新原稿に合わせ、必ず警告が出る前提にしない。
4. **見出しの判定条件**：ガイドは「直後の半角スペース」を説明しているが、現行 `parseHeadingLine` の正規表現は `\s` または行末を許容する。タブ・全角スペースや、記号だけの行も検出対象になり得る。記述を厳密な仕様として公開する前に、意図する判定条件と実装を揃える。

設定と実装の確認候補：自動保存待ち時間の設定下限は0.3秒だが、作品設定画面は0.5秒以上へ補正している。ノート・構想メモは0.3秒以上。通常の既定0.8秒には影響しないが、下限を説明する場合はこの差を先に確認する。導入版は変更履歴から特定できないため、版別追加機能には数えない。

### 優先3：掲載画像・補足の更新

- v1.0.63の新アイコン、v1.0.64の補助タイトル、v1.0.65の呼び名全体プレビュー、v1.0.68の自動保存バッジ・更新・履歴・進捗画像が写る最新画面へ差し替える。
