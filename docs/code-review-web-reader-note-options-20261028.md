## 変更

原稿のノート参照の参照元作品／種類／ノート選択と状態案内を「参照元・表示設定」のdetailsへまとめ、初期は折りたたむ。ノートプレビューと共通の開閉・高さ制限・要約のスタイルを再利用し、展開中も最大55%までとして本文の領域を残す。

閉じた状態でも、現在作品または関連作品名、参照のみ、プロット／資料、選択中のノート名を要約する。読み込み中のバッジと確認事項の有無も表示する。参照元・種類・ノートの切替と読込完了へ要約が追従し、展開で従来の選択欄と詳しい案内を確認できる。開閉はネイティブsummaryでタップ・クリック・Enterから操作する。

編集中の原稿・選択作品・保存先・dirtyや読取専用性は維持。開閉状態を描画でリセットせず、読み込み完了や切替でも維持する。内蔵／独立ガイドへ開閉操作を追記。

狭幅の確認で既存の100vwによる幅指定がスクロールバー幅を含み、パネル左端が9pxはみ出すケースも確認。原稿参照パネルのモバイル幅を100%基準へ修正し、390px iframe（実際のレイアウト幅375px）で左6px・右369pxに収まることを確認した。
