## 操作と保存

作品設定の「関連作品を設定」から、同じクラウド・作品ルート内の相手を選び、「関連付ける」「解除する」で両作品のworkId／relatedWorkIdsを更新する。通常の作品設定の自動保存とは別に相手ごとの操作で確定する。作品設定が編集中なら先に既存の保存処理を通し、失敗・競合時は開かない。設定ファイルやフォルダは自動作成しない。設定がない作品は既存の作品設定で保存し、Google Driveでは追加許可を確認する。

読み込みだけではIDを作らず、明示的な関連付け時に限って不足IDを保存する。生成IDは相互参照を書き込む前に両側で確定させる。保存直前に候補と設定を取得し直し、重複ID、読込失敗、移動した設定、保存先drive・親フォルダ不一致、版情報不足を拒否する。Dropboxの親は正規化されたパスで検証する。

JSONの未知フィールド、他作品との関連、候補に出ない関連IDを保持する。eTagによる既存の条件付き書き込みを使い、競合を上書きしない。相互保存は非原子的なため、片側成功を巻き戻さず、モーダル内に未完了と「再試行」を表示する。再試行は最新状態から不足した側だけを保存する。作品設定の編集元も成功済みの自作品設定へ更新し、後の自動保存による差し戻しを防ぐ。

書き込み中は閉じる・画面移動を抑止する。候補の読み込み中は閉じられ、閉じた後や接続・作品変更後の応答は破棄する。未完了の操作意図は同じ接続・作品のセッション内に保持する。ページ再読込を越えるトランザクション記録はなく、再読込後は片側関連の検出から修復する。
