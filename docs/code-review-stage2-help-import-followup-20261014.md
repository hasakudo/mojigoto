## 専用ページの情報整理

常時表示は接続・登録済み作品・許可作業・取り込み／選択／登録復元・中断／リセットを中心とし、以下を固定の「Google Driveのヘルプ」へ移動した。

- 許可するフォルダの見本（Single／Multi）
- VS Codeでも同じ作品を使うには
- ファイル／フォルダを許可するについて
- 新規ファイルの追加許可と、Webで使わない項目
- 接続許可を取り消したい方へ
- 登録済みの作品フォルダを削除・変更した場合（登録解除もここから操作）

幅1280px以上は右側パネルとなり、メインの操作画面を横に配置する。狭い画面はネイティブdialogのモーダルで、フォーカスを内側に保つ。どのスクロール位置でも固定ボタンから開ける。閉じる／Escapeで操作元へ戻り、幅変更後も開いた項目・読んでいる位置を保持する。見本の既存URL `#setupFolderExamples` とメインの直接リンクもヘルプを開く。

処理中もヘルプと通知の閉じるボタンは使える。ヘルプ表示中は同じ操作通知をヘルプ内へ移し、閉じるとページへ戻す。モーダルの背後へ警告が隠れる問題を避け、既存の閉じるまで残る状態・警告優先を保持する。

## 許可済みの別作品フォルダへの入口

登録済みの状態にも「別の許可済み作品フォルダへ切り替える」を追加。「取り込み済み作品の登録を復元する」を「許可済み作品へ切り替える・登録を復元する」へ変更し、PC取り込み済みと、既存作品を手動許可して登録した場合を同じ選択経路で扱う。

Singleは使いたい作品フォルダ、Multiは作品が並ぶ親フォルダを選ぶ。許可済みのファイルを検出して登録し、複製しない。キャンセル・作品確認失敗では前の登録を保持する。未許可項目は自動検出できないため、必要な作品を確認できない場合は「Driveにある既存作品をそのまま使う」から追加許可する案内を表示する。選択肢の欄は登録済み／完了後にも使えるようにし、手動許可処理の途中は隠す。

## PC複製とWebの追加許可を分ける

最初の修正では `.vscode` を技術用データとして一律除外しており、PC複製後にVS Codeの設定が失われた。既存作品のWeb許可省略とPC複製の保持対象を混同したため、方針と実装・説明を修正した。

| 対象 | PCから新しいDriveフォルダへ複製 | 既存Drive作品をWebで使う際の追加許可 |
|---|---|---|
| `.vscode` | 設定を保持。任意除外の対象にしない | 現行Webは使わないため省略可。Drive上から削除しない |
| `_WORK` | Multiの表示用として空フォルダを用意。中の原稿は重複コピーせず、各作品の正本を保持 | Webの作品ではないため省略可。元データは削除しない |
| 書き出し専用ExportRoot | 任意除外できる。原稿・`.mojigoto`を含む場所は一律除外しない | Webで使わない書き出し専用部分は省略可 |
| `.git`・node_modules・.local-config・.env系 | 自動除外を維持 | Web作品編集には不要 |

空の `_WORK` はブラウザのFileListへ出ないため、Multi作品のwork.json構造からも判定して用意する。VS Codeの初回セットアップ・作品切り替えでも必要なフォルダを作ることを既存の実関数テストで確認した。原稿リンクの再設定は作品切り替えで行い、G:でjunctionを作れない場合の直接参照を維持する。既存の `_WORK` をユーザーが手動削除する手順は追加しない。

PC複製の `.vscode` 配下へ、アプリ管理の `mojigoto-import-source.json` を生成する。kind・versionと取り込み元／取り込み先の**フォルダ名だけ**を保持し、元PCの絶対パス・認証情報はこのメタデータへ追加しない。再取り込みでは旧メタデータをそのまま複製せず、今回の出自で1ファイルを作成する。

対応版VS Code拡張の起動時にこの出自を使い、既存のコピー先パス修復を任意の取り込み名にも適用する。現在のSingle／Multiの構造と参照先を確認し、元作品内の `manuscriptRoot`・`workRoot`・`exportRoot` だけを読み替える。モード・表示設定・他の設定を保持し、もともと外部にある書き出し先は変更しない。すでに取り込み先を参照している場合は変更しない。

この追従には今回の修正版VSIXが必要。コピー元に `.vscode` がない作品は設定を復元できない。また、以前の除外版で取り込み済みのDrive作品に設定ファイルを後から自動復元する処理は追加していない。既存作品は変更しない。
