# 追加修正5：作品ツリーのごみ箱件数（2026-10-25）

## 変更

構想メモの復元タブ表示は利用者確認済み。合意順5としてごみ箱の件数表示を追加。

- ごみ箱のラベル「ゴミ箱」の横へ、ツリーのdescriptionで「0件」「3件」のように表示する。単一作品、View連携中の作品、作品一覧から展開する各作品のごみ箱が対象。
- 件数は復元対象となるごみ箱直下のエントリ数。フォルダーも1件とし、内部のファイルを合算しない。既存の一覧と同じく`.mojigoto-trash.json`のメタデータは除外。メタデータだけが残った場合も数えない。
- `countTrashEntries`は直下の名前一覧を1回だけ読み、本文・メタデータの読込や再帰走査は行わない。ディレクトリを作成せず、表示されるごみ箱の描画時だけ取得する。件数キャッシュは持たない。
- ごみ箱がまだ存在しない場合は0件、取得に失敗した場合は「件数不明」とし、アクセス失敗を空のごみ箱と誤表示しない。次の再描画で再取得する。
- 削除・復元・空にする操作は既存のツリー更新を使う。作品切り替え後も対象ごみ箱のパスから数え直す。コンテキスト値・アイコン・操作・保存形式は変更しない。
- 版は1.0.68。インストール・公開・コミットは行わない。
