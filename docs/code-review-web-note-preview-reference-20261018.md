# Webノート編集画面で他ノートを参照（2026-10-18）

優先3のプレビュー表示維持は利用者確認済み。優先4として、プレビューへ「種類」「ノート」の選択欄を追加した。

種類「編集中」は従来の下書きプレビューで、区分・項目から現在の編集位置へ移動できる。ここを開くだけではノート一覧の通信を行わない。「プロット」「資料」は同じ作品の他ノートを選び、原稿画面と共通の描画で参照する。編集中のノートは他ノート一覧から除き、「編集中」で戻れる。他ノートの項目は参照専用とし、現在の編集画面への誤ったジャンプを防ぐ。

他ノートを参照しても、編集中のノート・種類・未保存状態を変更しない。編集・保存によるプレビュー更新時も、他ノートの選択・大分類の開閉・スクロールを維持する。同じ編集ノートでは閉じて開き直しても選択先を維持し、別のノート・作品・接続先では「編集中」へ戻す。再読み込み後の参照先の永続保存は今回追加していない。

参照には既存の一覧キャッシュと読み込み処理を共用する。参照用の読み取りでは保存先フォルダを新規作成しない。Google Driveで保存先が未許可なら追加許可の案内を表示する。種類の変更・閉じる・作品／接続先／編集ノートの切替後に届いた古い応答は採用しない。共有の一覧・フォルダ読み込みも作品／接続先を確認し、別作品へ一覧とキャッシュを混ぜない。

Web本体・boot 1.0.202／SW v247、styles.css 1.0.180。設定ファイルの変更は不要。
