# Web自動反映設定・編集画面からのガイド（2026-10-18）

## 変更

- ノートの歯車に「構想メモへ自動反映」、構想メモの歯車に「項目メモへ自動反映」を追加。Web専用の方向別の許可設定で初期ON。このブラウザの全作品で共通、localStorageへ保存し再読込後も維持する。
- 自動保存と独立。OFFでも編集内容を自動・手動のどちらでも保存でき、手動反映も使える。作品データの個別反映設定・VS Codeの設定は変更しない。ONにするだけでは保存・反映せず、未連携のコピーへ連携を作らない。
- 保存後の反映に加え、構想画面から逆方向へ反映する経路にも設定を適用。連携先の読込待ちにOFFにした場合は送信前に確認する。送信済みの処理を取り消す機能ではない。
- 初回の同期基準がなく両方向の個別設定がONの場合、片側のWeb設定をOFFにしても反映方向を推測して上書きしない。従来の競合停止を維持する。
- 原稿・ノート・構想メモ・作品設定の歯車に保存ガイドを追加。原稿・ノートにはファイル読込ガイドも追加。作品設定の自動保存は歯車内にまとめた。編集欄への説明文は追加しない。
- ログイン後ガイドに自動保存と自動反映の違い・設定範囲・手動反映の説明を追加。バックアップと「履歴」の現在の入口も修正。
- ファイル読込の項目を目次へ追加。通常Markdown・専用形式1〜4、ドロップ、自動生成、原本／コピー／上書き、再反映の競合、画像・呼び名一覧・構想メモ連携を整理。
- ガイドは編集画面を維持して別タブの該当見出しを開く。閉じた詳細を展開してスクロールし、同じガイドの別項目にも移動できる。別タブを開けない場合は画面内ガイドへ戻す。新規原稿・ノートの作成画面からも参照可能。
- Web本体・boot 1.0.194、Service Worker v239、guide CSS/JS 1.0.156。拡張の実行コード・生成形式は本作業では変更していない。
