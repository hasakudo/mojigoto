## 初回 W18-A：編集中の1ノート

対象はWebで編集中のプロット／資料の1ノート。未保存入力を含め、関連作品の読み取り専用ノートは対象にしない。ノート編集画面の歯車に「検索・置換」を追加し、モーダルで操作する。最初に保存を要求せず、検索だけなら未保存状態や保存予約を変更しない。ブラウザのCtrl+F・Ctrl+Zは横取りしない。

| フィールド | 初期対象 |
| --- | --- |
| 大分類名・区分名・補足・項目名 | ON |
| 項目詳細 | ON |
| 項目メモ本文 | OFF、利用者がONにできる |
| ノート名・ふりがな・タグ・リンク表示名・呼び名一覧・ID・同期情報 | 対象外 |

文字列検索のみ。大文字・小文字の区別は初期OFFで切替可能。空の検索語は実行不可、空の置換文字は削除として許可。正規表現、全角半角や読みの自動同一視は初回に含めない。置換文字の$1・$&は文字列として扱う。

通常文字の一致とルビ・傍点の保護箇所を結果に表示する。検索は保護部分の一致も場所へ移動できるが、置換ボタンは付けない。有効なルビ記法全体を保護し、不完全な記法はそのフィールドを置換対象外として理由を示す。置換で新しいルビ等の記法が成立したり保護範囲が変わる場合も適用を止める。

### 操作

1. 検索語・置換文字・対象フィールドを入力する。検索だけでも一致件数・場所・本文の抜粋から目的の入力欄へ移動できる。置換しない操作で編集状態を変えない。
2. 候補ごとに大分類／区分・項目／フィールド／行と変更前→変更後を表示する。場所を押すとモーダルを閉じ、必要な折りたたみを開いて一致文字を選択する。再度開いて検索条件を継続できる。
3. 「この箇所を置換」またはチェックした候補を「選択したN箇所を置換」で適用する。初期選択は0件。「全候補を選択」はページ外も含む有効候補が対象で、保護箇所は含めない。
4. 適用件数と「直前の置換を戻す」を表示する。空白・改行・空文字への変更も抜粋で区別する。候補はページ分割し、画面全体に巨大なDOMを作らない。狭幅はヘッダーと操作の見切れ・スクロールを確認する。

### 保存と戻す操作

- 現在のノート・接続・作品を固定し、対象フィールドとIDだけを更新する。置換・戻す1操作につき通常の未保存処理を1回呼び、自動保存ONなら既存スケジューラーへ渡す。
- 項目メモを対象にした場合は更新時刻を通常入力と同じ意味で更新し、保存時に自動反映設定へ従うことを表示する。同期リンク・指紋を直接消したり、表示上だけ反映完了にしない。
- 保存・反映・IME変換の最中は適用／戻すを抑止する。候補表示中の入力・並べ替え・追加削除・外部更新は候補を無効化して選択を解除。適用直前にも対象ID・元文字列・編集世代を照合し、不一致なら操作全体を中止する。
- 再読込や外部更新でstate.currentNote.dataが置き換わる場合も世代を変更し、単にdirtyがfalseになったことを安全の根拠にしない。保存でsnapshotへ置き換わった場合は内容を照合して候補を再計算する。
- 「戻す」は変更したフィールドの文字列差分だけを1操作分保持する。ノート全体のスナップショットを上書きせず、無関係な編集・同期メタデータを保持する。戻す対象を後から変更・削除した場合は一部だけ戻さず通知する。
- 自動保存後も同じ編集セッションなら戻せる。戻した内容も通常保存・自動反映を通す。他画面や他端末まで一括巻き戻しはしない。次の置換で戻す対象を更新し、別ノート・別作品・切断・再読込時に破棄する。
- 検索語・候補・戻す履歴をlocalStorageや共有キャッシュに保存しない。条件の保持は同じ編集セッションのメモリ内だけ。
