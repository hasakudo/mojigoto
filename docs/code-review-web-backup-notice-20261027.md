# バックアップ通知のモーダル内表示修正（2026-10-27）

利用者がバックアップ操作に問題なしと確認。2-C1の入出力分離は利用者確認済み（環境の個別明示なし）。ただし操作時の通知がモーダルの背面に表示されると報告を受け、次の構造整理より先に修正した。

## 原因と変更

notifyがモーダル内の既存通知欄を更新した後も共通トーストを表示していた。共通トーストはモーダル外にあるため、dialogの背面に出ていた。

バックアップを開いている間は既存の内部通知欄だけを更新して処理を終了する。共通トーストの既存タイマーを解除し、表示中の共通通知も隠す。内部のエラーは後続の成功通知で消さず保持し、通知の閉じる操作を維持する。バックアップを閉じた後の通常通知は従来どおり共通トーストを使用する。

内部通知にsticky位置と不透明な背景を指定し、モーダルをスクロールしても読めるようにした。保存、バックアップ作成、比較、保護、復元の処理は変更していない。

## 検証

全1,599件成功、失敗0。追加1件で既存共通タイマー解除と表示解除、内部通知中に共通タイマーを作らないこと、エラー保持、モーダルを閉じた後の通常通知への復帰を確認。既存の内部通知とエラー保持テストも継続。

仮データのブラウザで手動バックアップ作成と保護の通知が内部にだけ表示されることを確認。20件の履歴で末尾の保護操作を行い、履歴欄scrollTop=1074、モーダルscrollTop=96の状態でも通知領域は画面内（top=74、bottom=138）にあり、共通トーストは非表示。通知を閉じても背面に共通通知が残らないこと、ブラウザエラー0件を確認した。実クラウドでの通知やモバイルは未確認。
