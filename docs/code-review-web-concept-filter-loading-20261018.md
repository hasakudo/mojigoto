# Web構想メモのノート候補と読み込み表示（2026-10-18）

VS Code／Webの構想メモの絞り込みは利用者確認済み。Webの候補整理とLoadingの追加指摘を修正した。

- Webのノート選択は、現在の作品に実在する構想メモと関連するノートだけを候補にする。出典と項目メモ側のリンクをどちらも確認し、複数リンクも対象にする。消したメモのIDだけが残るノートは候補に含めない。
- 候補の有無は作品の全構想メモで決める。保管中のメモも対象。検索・フォルダ・タグ・状態の操作中に候補を増減させない。実際の一覧は従来どおりこれらの条件とANDで絞る。
- 保存済みの選択が「参照できるが関連メモのないノート」になった場合は「すべて」に戻し、その表示設定だけを保存する。未取得や参照不可の選択は従来の保護を維持する。ノート・構想メモの実データは変更しない。
- これまでLoadingは作品文書が未取得または別作品の場合にしか表示されず、同じ作品の期限切れ再取得では表示されなかった。また、前回のメモ編集画面の復元ではreveal=falseで全画面が隠れていた。キャッシュが新鮮でない取得では一覧を一時表示してLoadingを出し、ページ切替を隠してaria-busyを付ける。
- 新鮮なキャッシュの再利用ではLoadingを挟まない。取得失敗時はLoadingをエラー案内へ置換し、aria-busyを解除する。編集画面復元のルート確定やノートの先読み範囲は従来どおり。

Web本体・boot 1.0.205／SW v250、styles.css 1.0.181。Webのみの修正で、VSIX・設定変更は不要。
