# 追加修正3：関連リンクの区分名・補足の選択（2026-10-25）

## 方針と変更

入力補助とプレビュー末尾の修正は利用者確認済み。合意順3の関連リンク名を修正。

- 従来は関連ノート検索の区分タイトルが常に補足優先で、関連付け時にもその文字列だけをリンク名として保存していた。
- 「名前／葉月」と「アリス／王国の剣士」は区分名と補足という同じ構造であり、どちらが固有名かを確実には自動判定できない。名前・名称などのキーワード判定は使わず、従来の補足優先を初期値として、リンク単位で表示名を選べる形にする。
- 検索結果の区分に異なる区分名と補足が両方ある場合、「リンク名」のセレクトで具体的な候補を表示する。未関連なら選択後に関連付け、関連済みなら選択時にそのリンク名だけを変更する。検索タイトルと関連リンクのチップも追従。
- 既存の区分リンクのチップには鉛筆ボタンを追加。現在の参照先を解決し、VS Codeの選択欄で区分名／補足を選び直す。古いリンクに候補メタデータがなくても変更可能。参照先不在はエラー、取消は変更なし。
- 応答の要求IDと元のリンクキー・変更前の名前を照合する。別の要求の遅い応答、関連解除後、別の名前変更後の応答で内容を巻き戻さない。
- 選択結果は従来の`itemLabel`文字列に保存する。リンクID・本文・元ノートの区分名／補足は変更せず、データ形式も増やさない。表示名は従来同様に関連付け時点の文字列で、今後の参照先改名へ自動追従するモードの追加ではない。Webへの既存形式の互換性を維持する。
- 検索結果には区分名／補足を候補情報として付加する。項目は既存どおり項目名を使用し、選択UIを増やさない。片方が空・両方同じ場合も検索結果の選択UIは出さない。
- 版は1.0.68。インストール・公開・コミットは行わない。
