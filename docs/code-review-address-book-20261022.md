# 4-C 呼び名一覧の画面・編集・保存応答の分離（2026-10-22）

## 整理範囲

4-Bの通常・表示専用・ボードプレビューは利用者動作確認済み。今回は呼び名一覧の編集・保存・別タブ管理を整理する。

実機確認の追補：下の行に呼び名候補が重なる問題を[別の不具合修正](code-review-address-picker-position-20261022.md)として対応。修正版での確認待ち。

- `src/views/address-book/html.js`へ独立タブのHTML・画面初期化の組み立てを分離。既存ノートCSSと、ノート内／独立タブで共有する編集スクリプトを引き続き使用する。
- `address-book/host-actions.js`へ独立タブの操作受付・書き出し処理を分離。保存・読込は既存の`address-book-session.js`へ委譲し、書き出し前の保存版照合、取消・失敗の通知を維持する。
- `address-book/script-renderer.js`へ呼び名候補・人物候補・行列の絞り込み・編集表・全体プレビューの描画を分離。
- `address-book/script-actions.js`へセル入力、人物の追加削除、開閉・各ボタンの操作登録を分離。
- `address-book/script-sync.js`へ保存待機・保存中の追加入力・保留操作と、読込／保存／他画面からの更新応答を分離。
- 既存の`note-webview/script-address-book.js`は状態・データ整形と各部の組み立てを扱う。ノート内と独立タブで同じ状態・同じ関数スコープを使用し、初期化やイベント登録の順序は変えない。
- 作品の選択・保存先の確定、独立タブの再利用・破棄・復元とステータスバー登録は元のホストに残す。公開API、共有保存セッション、データストア、ノート側の操作受付は変更しない。

画面と保存の仕様を変えない整理。名前の省略・ホバー表示、区分名の参照、候補の絞り込み、保存完了を待ってからの別タブ／書き出し／閉じる操作を保つ。初回ジャンプや項目メモ一括開閉・目次ボタン移動は今回に含めない。
