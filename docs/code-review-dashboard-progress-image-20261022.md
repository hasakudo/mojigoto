# 5-C1 DashboardのSNS画像保存（2026-10-22）

## 変更

比較確認のON／OFF切り替えは利用者確認済み。5-CをSNS画像保存と集計補正に分け、最初に画像保存だけを整理した。

- `stats-panel.js`のSNS進捗画像保存を`dashboard-progress-image-actions.js`へ移動。メッセージ分岐、パネルの管理、投稿データ・プレビュー生成はホスト／既存部品に残す。
- 画像データの検証・デコード、日付／作品名からの既定ファイル名、保存先ダイアログ、PNGバイトの書込み、保存先の記憶と応答・通知をそのまま分離。
- 保存先は記憶したURIを優先し、解析に失敗した場合や未設定時はワークスペースを使用する。ワークスペースなし、リモートURIのscheme／authority、親URIのquery／fragment除去を維持。
- ファイル名の作品名非表示、禁止文字の整形、作品タイトル不在時のフォールバック、不正日付のUTC日付へのフォールバックも維持。ファイル名や日付規則の変更は混ぜていない。
- 取消は書込み・保存先更新を行わず取消応答を返す。成功はファイル保存→保存先記憶→応答→完了通知、失敗はエラー応答→エラー通知の順を維持。
- 保存先の記憶に失敗した場合に、ファイルが保存済みでも処理を失敗として返す従来の動作も変えていない。
- 画像の見た目、集計、キャッシュ、設定、Web配布コードは変更していない。版は1.0.68。インストール・公開・コミットは行わない。
