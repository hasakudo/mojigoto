# ノートの大分類挿入と項目・メモ開閉（2026-10-31）

## 変更

Web **1.0.282**／シェル **v327**／共有CSS **1.0.211**。プロット・資料共通のノート編集へ追加した。

- 各大分類の末尾に「＋ 大分類」を配置し、その大分類の直後へ空の大分類を挿入する。最後の大分類からは末尾に追加する。既存のノート末尾専用ボタンをこの配置へ統合し、上部の追加ボタンは末尾への追加として維持した。
- 挿入後は新しい大分類名へスクロール・フォーカスする。既存のID・本文・項目メモ・関連リンク・画像などはそのままに、groups配列へ新しいIDを持つ分類を挿入し、通常の未保存・自動保存経路へ渡す。保存・同期・削除中は追加しない。待機中に別ノートへ移動した場合はフォーカスを移さない。
- 従来の「項目を開く」「項目を閉じる」を1つの切替ボタンに統合し、「メモを開く／閉じる」も別の切替ボタンとして追加した。項目詳細と項目メモを独立して一括開閉する。
- 全件開いていれば「閉じる」、閉じているものが1件でもあれば「開く」を表示する。個別の開閉にも文言・アクセシブルなラベル・展開状態を追従させる。対象のない空ノート・区分のみの場合は無効にする。
- 開閉は表示状態だけを変更し、ノート本文を変更せず未保存扱いにしない。状態を即座に記録して、直後の分類追加などの再描画でも維持する。破棄済みDOMの遅れたtoggleイベントから現在の状態を書き戻さない。

保存形式の変更はない。以前からのnoteDisclosureと同じく、画面内の開閉状態であり、ブラウザを再起動しても維持する新しい設定は追加していない。
