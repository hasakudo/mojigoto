# SNS進捗画像用の共通データ形式

VS Code版とWeb版が同じ進捗画像を生成するための、表示に依存しない中間データです。現在の形式は `schemaVersion: 1` です。

## 集計ルール

- 日付と「今日」の判定は既定で `Asia/Tokyo` を使用します。
- 日別データは対象日までの7日間を古い順に並べ、記録がない日は0文字として補います。
- 今日・直近7日の文字数には減少分も反映するため、負の値を許可します。
- 総文字数は0以上です。
- ノートと構想メモの更新件数は、対象日に更新された重複しない項目数です。
- 作品名を非表示にした場合、`work.title` は空文字になり、出力データへ作品名を残しません。

画像の配色、背景、フォント、画像サイズ、表示項目の選択はこの形式に含めず、画像作成側の設定として管理します。

## 個人情報を含めない項目

メールアドレス、利用者ID、クラウドID、ファイルID、ローカルパス、原稿本文、ノート本文は出力しません。

正式な定義は [progress-summary.schema.json](./progress-summary.schema.json) を参照してください。
