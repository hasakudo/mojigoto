# 選択インポート下部の見切れ修正（2026-10-19）

強調したメモ説明文で上部の高さが増えると、候補・挿入先が固定フッターの下へはみ出す問題を修正。

- 対象は`src/views/note-partial-import-webview.js`の高さ計算と末尾余白。読込・保存・メモ選択の処理は変更していない。
- 候補・プレビュー・挿入先／上書き先の現在位置から、フッター上端までの空間を測定。従来の大きな最低高さを外し、プレビューの変更後に挿入先の位置を測り直す。
- 挿入先／上書き先はカード全体をborder-boxで制限してスクロール。内容だけの高さとカードのパディングを二重に加算しない。
- フッターの実測高さに16pxを加えた末尾余白を全幅で確保。非常に低い画面・1カラムではページスクロールで末尾へ到達できる。
- ヘッダーとフッターをResizeObserverで監視し、説明文やボタンが折り返した場合も再計算する。
