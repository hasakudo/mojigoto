# Webノートプレビューを保持して編集位置へ移動（2026-10-18）

VS Code表示専用プレビューの項目メモ一括開閉は利用者確認済み。優先3として、Webノートプレビューの区分・項目を選ぶたびに `moveToNotePreviewTarget` がダイアログを閉じていた処理を削除する。

プレビューを開いたまま対応する編集カードへスクロールし、区分名・項目名の欄へフォーカスする。プレビュー内容を作り直さず、大分類の開閉とプレビューのスクロール位置、未保存の内容を保持する。閉じるボタン、プレビュー内のEscape、編集画面を離れたときの終了処理は従来どおり。画面幅による配置・高さは変更しない。広い画面は右側に並び、狭い画面は従来の重ね表示となり、必要に応じて閉じる操作で編集欄を広く使える。

Web本体・boot 1.0.201／SW v246、styles.css 1.0.179。設定ファイルの変更は不要。
