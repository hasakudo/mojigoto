## 初回ONと既存設定の保護

新しいDashboard・ノートの操作は、初回ONの既存確認を**設定適用前**に行う。確認中はOFFを維持し、キャンセルは変更しない。「すべてONにする」は個別未指定の既定をONへ変更する意味で、明示的な個別OFFを消さない。確認済みなら再質問しない。

「既存はOFFのまま」を明示的に選んだ場合だけ、未指定の既存メモへ個別OFFを記録する。既存の個別ON／OFF、旧形式のON、本文、未知項目は保持する。この経路に残っていた直接writeFileを、読み込み時の版照合・仮ファイル置換による保存へ変更した。競合・不正JSON・フォルダ読み込み失敗では既定をONにせず停止する。Multiでは作品ルートの読み込みも先に確認する。複数ファイルの途中で停止した場合、既に記録済みの個別OFFを巻き戻す処理は追加していない。既定はOFFのままで、新たな既定による反映は開始しない。

変更したメモは既存の編集画面更新通知を使う。未保存の画面は既存の外部更新ガードで入力を保持し、必要に応じて更新を案内する。設定の操作要求は同じキューで順に扱い、確認中に続けて届いたON／OFFが順序を逆転しないようにする。

Dashboardの失敗は閉じるまで残る通知で表示し、チェックを確定値へ戻す。後続の成功で警告を消さない。ノートの設定失敗も既存の閉じるまで残るエラー通知を使用する。

VS Code標準の設定画面で直接変更した場合の既存の初回確認も維持する。適用前に確認する保証は今回の新しいDashboard・ノート操作に関するもの。
