保存から同期、同期から同期情報の保存という循環はコールバックでつなぐ。共通タイマーから保存、共通外部監視から出典更新確認を呼ぶ経路は遅延転送し、定数の初期化順序を保つ。コントローラーの生成時には通信や保存を開始しない。同期指紋・ペイロード変換等は既存の専用モジュールを利用する。

出典取得後の接続先・作品・メモ・文書の照合、書込中の同期フラグ、下書きを守る比較、条件付き書込を維持した。二つ目の保存に失敗した場合を成功として通知しないこと、通信中の追加入力を未保存で残すことも従来どおり。
