# 5-B2 Dashboardの執筆メモ：更新・状態・保管・復元・削除（2026-10-22）

## 変更

利用者は5-B1の執筆メモ動作を確認済み。今回は次の6操作を`stats-panel.js`から`dashboard-writing-memo-operations.js`へ移動した。

- 本文更新、状態変更、完了メモの一括保管、保管済みメモの一括削除、復元、単体削除。
- 既存の保存先解決をホスト経由で使用。本文・状態変更で明示された保存先を優先し、その他の操作は現在作品の保存先を使う。確認ダイアログの前に解決した保存先を処理中に変更しない。
- 本文更新は保存成功後にホストのコールバックで編集状態を解除。空本文・対象不在・保存失敗では編集状態を解除しない。
- active／hold／doneへの変更は保管を解除し、archiveは既存の状態を維持して保管。復元も状態は変えず保管のみ解除する。
- 元の確認ダイアログ、対象の有無の判定、未知のJSON項目を保つ書込み、保存→再描画→装飾更新→結果通知の順序とエラー処理を維持。
- メッセージの分岐順、パネル寿命、編集開始／取消、作品／ファイルの一覧操作、構想メモへのコピー、装飾切替はホストに残す。保存キューや新しい確認を追加していない。
- 画面、保存形式、集計、キャッシュ、Web配布コードは変更していない。
