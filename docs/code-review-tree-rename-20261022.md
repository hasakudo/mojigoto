# 6-C1 作品ツリーの名前変更（2026-10-22）

## 変更

作品・原稿・章フォルダの作成操作は利用者確認済み。名前変更・移動・ゴミ箱は関連更新と失敗時の扱いが異なるため、まず名前変更だけを分離した。

- 原稿・ノート・章フォルダ・作品フォルダの名前変更と、その専用の入力ダイアログ、JSON内の名前更新、作品別集計キーの移行を`work-tree-rename-actions.js`へ移動。
- コマンド登録と最上位の例外通知は元のホストに維持。移動・削除も使う実名変更、存在確認、バックアップ／表示名移行、タブ終了、ツリー再表示はホストに残して注入する。
- 原稿の拡張子保持、同名確認、取消・変更なし、章内のタブ終了、ノートJSONのタイトル変更と旧ノート画面終了、View連携中作品の変更拒否、作品設定・集計情報・既存作品移行サービスの更新順を維持。
- 専用処理の本体は改行・インデントを除き着手前と一致。JSON読書き失敗をfalseで返す既存動作、バックアップ／表示名移行に失敗しても警告して続ける動作、その他の移行失敗を最上位のエラーへ渡す動作を維持する。新たな巻き戻しや確認は追加しない。
- 移動・ゴミ箱・復元、作品切替・監視・起動接続は今回変更しない。Web・保存形式・集計計算も未変更。版は1.0.68。インストール・公開・コミットは行わない。
