# 構想メモの2パネルの重なり（2026-10-18）

## 変更

追加予定7項目を優先順へ整理し、操作を妨げるWebの重なりを優先1として修正。次はVS Codeの表示専用ノートプレビューの項目メモ一括開閉。

構想メモ一覧の固定パネルとノート参照が右上の同じ領域を使い、一覧のz-indexが参照より上にあるため、参照の見出しや閉じるボタンを覆っていた。

840px以上では、両方の表示時に右側の上を一覧・下をノート参照へ配分する。一覧の内容を表示領域の約3割へ収め、内部でスクロールする。一覧の実際の下端から10px以上離してノート参照を配置する。一覧を閉じると、その分の高さを参照へ戻す。パネル同士の表示を排他的にせず、両方を開いたまま使える。

一覧の開閉・非表示、参照の開閉、ウィンドウのリサイズ、文字折り返しによるパネルのサイズ変化に応じて再配置する。編集データや保存・自動反映は変更しない。840px未満の参照パネルの配置は従来のまま。

Web本体・boot 1.0.196／SW v241、styles.css 1.0.176。設定ファイルの追加変更は不要。
