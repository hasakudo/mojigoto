# 比較確認ON時の表示条件の修正（2026-10-22）

## 原因と変更

前回の設定はONでも、従来の「構想メモ側の内容変更あり／内容指紋なし」という条件を残していた。そのため未編集の反映先では比較確認を省略していた。利用者が期待するON／OFFと一致していなかったため修正した。

- 設定`mojigoto.confirmWritingMemoConceptOverwrite`がON（既定）なら、既存更新時に毎回比較確認を表示。構想側が未編集の場合や、同じ内容を再反映する場合も表示する。
- OFFなら比較だけを省略する。更新／新規作成・複数候補の選択は従来どおり。
- 比較の案内文は、未編集なら現在と反映後を確認する案内、編集済みなら編集あり、古いコピーなら以前の内容を確認できない案内にする。
- 取消では更新しない。省略付き更新、更新成功後だけ設定を保存する処理、再読込・競合保護は維持。
- 設定の説明も「既存更新時に毎回比較確認を表示」に変更。
- applicationスコープは変更しない。この設定は全プロファイル・全作品共通で、ワークスペース設定には表示されない。
