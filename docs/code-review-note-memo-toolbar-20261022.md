# 項目メモの連動一括開閉と目次ボタンの移動（2026-10-22）

## 利用者確認と今回の変更

初回ジャンプの修正は利用者がワンクリックで移動することを確認済み。続いて追加予定の2点を実装した。

- ノート編集の「＋大分類」の並びとリストプレビュー上部に「メモを開く／メモを畳む」を配置。本文またはタグのある項目メモを一括で開き、畳む操作では個別に開いた空メモも閉じる。大分類の折りたたみは維持する。
- `script-memo-visibility.js`にノート内の開閉状態を集約。一括操作だけでなく、編集側の個別操作とリストの開閉も連動し、複数のメモを同時に開ける。状態は画面内だけに持ち、保存・自動反映を起動しない。再起動時は従来どおり閉じた状態。
- リストを再描画した際は共有状態から開閉を復元。生成時のtoggleイベントや、取り外された要素の遅延イベントで編集欄を不要に描画し直さない。検索で見えなくなった項目の開閉は維持し、削除された項目の状態は除去する。
- ボード内の個別開閉と、表示専用タブの既存一括開閉は独立したまま維持する。リスト側の一括ボタンはボード表示時には隠す。
- 調査するとVS Codeの検索は項目メモを対象にしていなかったため、項目メモ本文とタグも対象に追加。メモだけに一致した項目も編集・リストに残り、一括操作で内容を読める。検索欄の案内も更新。
- 目次ボタンをプレビューのボタン群から右上ヘッダーへ移動。既存ヘッダーと同じ34px幅のアイコンボタンとし、ツールチップ・読み上げ名・開閉状態と元のイベント連携を保つ。
