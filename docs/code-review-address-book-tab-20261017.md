## 実機確認

1. ノートの︙→呼び名一覧→「別タブで開く」。隣のタブで編集でき、元ノートは編集画面に戻ること。元ノートの未保存の本文が維持されること。呼び名を入力してすぐ別タブを開いても内容が引き継がれること。
2. 別タブで呼び名を変更し、元ノートの一覧を開き直すと反映されること。同じ作品から別タブを開き直してもタブが重複せず、閉じた後は再び開けること。元ノートを閉じても別タブで編集できること。
3. Multiで別の作品へ切り替え、それぞれの呼び名が混ざらないこと。二つの画面で同時編集した場合は先の保存を保持し、競合した側の入力が残ること。必要な入力をコピーし、「最新を読み直す」の取消／破棄確認から再開できること。
4. 狭いカラムで別タブ・閉じる・読み直しが見切れないこと。全体プレビュー・HTML／CSV書き出しも従来どおり使用できること。

確認後はWeb読込用Markdownの項目メモ・関連リンク・ふりがな等の拡張へ進む。
