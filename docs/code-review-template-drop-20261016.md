## 変更

ファイル選択欄を点線のドロップ枠にした。原稿はtxt／md、ノートはmdを1ファイルずつ受け付ける。ダイアログ内なら枠の外へ落としても読み込める。ドラッグ中は枠を強調し、離脱・ドロップ・閉じる操作で解除する。従来の選択ボタンも使える。

選択・ドロップを同じ読込処理へ接続した。文字コード・容量・生成形式の検証、ノート名の補完、冒頭プレビュー、内容確認後の作成を共用する。ドロップだけではクラウドへ保存しない。

複数ファイル・フォルダ・非対応形式は案内して停止し、前に読み込んだ内容と入力した名前を保持する。読込／作成中、作成済みファイルの再試行待ち、別作品へ移った後は内容を差し替えない。作成画面を開いている間は、枠を外したファイルドロップでブラウザが別ファイルへ移動しないようにする。通常のテキストのドラッグには介入しない。
