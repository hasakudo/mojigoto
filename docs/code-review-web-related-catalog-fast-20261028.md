## 修正

全作品が既知で追加調査が不要なら、ルート→全作品の子一覧→全管理フォルダ一覧の3段階がルート一覧1回になる。未知の通常フォルダも調べ、作品でないフォルダを候補に追加しない。通常の作品一覧の検出・並び順・集計には適用しない。追加の永続キャッシュは作らない。

OneDriveに読み取り専用のgetItemMetadataBatchを追加し、候補の設定情報を20件ずつまとめて確認する。返答は要求IDに対応付け、項目IDの不一致・個別失敗・batch自体の失敗は個別確認に戻す。成功とエラーはそれぞれ保持し、読めない作品を古い設定で補わない。この一括結果は保存前の版確認キャッシュへ登録しない。

現在作品の設定と各候補の設定本文は引き続きクラウドから読む。キャッシュの古いダウンロードURLは使わず、一括確認で得た項目を使用する。ノート本文を表示する前の関連解除・ID変更確認は従来どおり。作品タイトルのみの表示、未保存入力と保存先の保持も維持。
