## 接続期限と今回の変更

GoogleDriveAuthはGoogleが返したexpires_inを使い、60秒の余裕を引いて利用期限を決めている。30分固定のタイマーではない。GISのブラウザトークン方式は短期アクセストークンを使い、期限が切れたら利用者の操作で新しいトークンを取得する。[Google公式説明](https://developers.google.com/identity/oauth2/web/guides/use-token-model#token_expiration)。約30分という実測の原因（返却された有効期間、既存接続の経過時間、早期401等）は今回のコード・模擬テストだけでは確定していない。

期限切れ中の自動保存と外部監視による再試行を抑止する。401応答では使用したトークンだけを期限切れ扱いにし、古い応答が新しい接続を失効させないよう確認する。新しい期限通知は30秒ごとのローカル状態確認で、勝手にGoogleのポップアップを開かない。
