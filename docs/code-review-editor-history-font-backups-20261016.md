## バックアップの件数

| 対象 | 表示 |
|---|---|
| 原稿 | 従来の文字数 |
| ノート | 大分類 N・区分 N・項目 N |
| 構想メモ | 作品全体のメモ N件 |

構想メモは作品内の全メモをまとめるバックアップなので、保管済みも含む全メモ数を表示する。ノートの項目メモはノート全体のバックアップに含まれ、独立した件数とはしない。JSONのキーや管理情報を文字数として表示しない。

共有バックアップのschemaVersionは1のまま、構造化データのスナップショットと索引に任意の `contentSummary` を追加した。旧 `characters`、本文、ハッシュを互換性のため保持する。WebとVS Codeの形式処理で件数の生成・正規化・索引作成・再構築に対応し、保持整理や保護変更でも情報を維持する。VS Codeの構造化バックアップ画面は元々文字数を表示しておらず、UI変更の対象はWeb。旧クライアントが任意情報を落としても復元内容に影響しない。

古い索引等で件数情報がない場合は「件数未記録」と表示し、0件やJSON文字数を代用しない。比較を開いた際、取得済みスナップショットの本文から数え、比較見出しと一覧へ表示する。表示のために全バックアップを追加取得したり、索引を書き戻したりしない。復元前の検証・退避・保存基準は維持している。
