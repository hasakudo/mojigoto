# 新規作成のEnter送信（2026-10-31）

利用者から名前変更の注意表示と動作について問題なさそうとの報告を受け、新規フォルダ等にもEnter作成を追加したいとの要望に対応した。

## 対応

新規フォルダ・原稿・ノートの名前欄でEnterを押すと、既存の「作成して開く」と同じ処理を実行する。従来はフォーム先頭の「閉じる」が既定のsubmitになっていたため、閉じるをtype=buttonへ分離し、作成だけをtype=submitにした。submitter情報がない送信にも対応する。ファイル読込とノートの反映・上書きでは既存の確認条件と保存・再試行を維持し、専用の別作成処理を追加しない。

IMEのcomposition状態／isComposing／keyCode229で、変換確定中のEnterによる送信を抑止する。変換中のsubmitもcaptureで止める。変換終了後は通常のEnterで送信する。フォルダ作成では親一覧の重複確認前から処理中にし、Enter連打で二重作成しない。作成中の閉じる・Escapeと、作成待機中に次の新規フォルダパネルを開く操作も抑止する。

共通処理はweb/lib/create-dialog-form.mjs。app.mjsとindex.htmlへ接続し、起動版・シェル依存を更新した。Web1.0.276／シェルv321／共有CSS1.0.210。公開・反映・コミット、実クラウドへの書込みは未実施。
