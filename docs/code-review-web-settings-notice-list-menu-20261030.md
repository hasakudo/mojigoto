# 接続設定の通知と原稿一覧の歯車メニュー（2026-10-30）

Web1.0.271／シェルv316／共有CSS1.0.208。本番・テスト環境へは未反映。

利用者が前段階のプレビューから編集への導線と、表示設定パネルの左寄せを確認。報告範囲で確認済みとし、今回の通知修正と原稿一覧メニューへ進めた。

## 変更

接続設定はネイティブdialogでブラウザのtop layerへ表示されるため、通常画面に置かれた通知はz-indexを上げるだけでは上に出ない。接続設定が開いている間は共通のstatusMessageをdialog内へ移し、コピー成功・エラーなど既存の通知文をそのまま表示する。閉じた際に元のmainへ戻す。4.2秒の表示時間と通常画面の通知、バックアップパネル内の既存通知処理を維持。

原稿一覧では「全体プレビュー」「進捗画像」を常時表示から歯車メニュー内へ移動。新規フォルダ・新規原稿は従来どおり表示する。既存のeditor-options開閉・画面内への位置補正・外側クリック／Escapeを使い、項目を選択した際にもメニューを閉じる。各操作のIDと既存ハンドラを保持し、原稿編集画面内のプレビュー入口は変更しない。

ガイドの原稿一覧からの入口を歯車経由へ更新。

## 検証

全1,828テスト成功。既存の歯車数の検証は原稿一覧への追加に合わせて更新。バックアップ通知の既存テストも成功。ガイド生成の--check一致。

実クラウドを使わない仮データのブラウザで確認した。

- 原稿一覧の初期状態では全体プレビュー／進捗画像が見えず、歯車を開くと表示される。
- メニューから全体プレビュー・進捗画像の各ダイアログを開ける。選択後は歯車のaria-expanded=false。
- 接続設定を開いたまま速度計測結果をコピーし、「速度計測結果をコピーしました。」がsettingsDialog内で表示される。
- 無効なアプリIDを入力して保存を押すと、設定は保存されずエラー通知が同じdialog内へ表示される。
- 閉じるとstatusMessageの親がMAINへ戻り、settingsDialogは閉じた。通知を複製していない。
- 406px幅でも通知が設定モーダルの上に見える。仮データの通知位置は上711px／下763pxで画面内に収まった。メニューも画面内に表示された。

実機Android・本番／テストでの確認は利用者待ち。クラウドの接続情報の保存・認証・実作品の変更は行っていない。

## 原稿一覧の歯車サイズ修正（2026-10-30）

利用者が接続設定の通知を確認。残った原稿一覧の歯車の縦横不一致・アイコン右寄りだけを修正した。原因は.manuscript-list-actions buttonの共通左右12px余白と歯車の34px幅／38px高の競合。歯車に限定して38px四方・padding:0を指定し、他のボタンやメニュー動作は変更しない。

仮データの406px幅でボタン38×38px、アイコン16×16px、中心差は縦横とも0pxを確認。歯車の開閉と全体プレビューの項目表示も確認。CSSのみの局所修正のため新規テスト・全体テスト再実行は行わず、ブラウザの寸法・表示を検証した。
