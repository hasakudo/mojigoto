## 操作と表示

構想メモ編集画面の「一覧」を開き、「一覧プレビューを常時表示」をONにする。初期OFFで、同じブラウザの表示設定へ保存する。Driveの作品ファイルへは保存しない。

840px以上では一覧を編集欄の左に並べ、狭い画面では編集欄の上で開閉できる。ノート参照パネルを同時表示する際は1400px未満で一覧を上へ移し、編集欄が過度に狭くなるのを避ける。表示幅を変えても設定はOFFへ戻さない。一覧の開閉そのものは再起動用の設定にはしない。

既存の編集用一覧と同じ文書・順序を使い、タイトル、TEXT／LIST／TODO、本文または項目の先頭2行、編集対象・未保存を表示する。HTML風の本文も文字として扱う。一覧表示のためのクラウド取得は追加していない。入力による更新時も一覧のスクロール位置を保つ。

## 保存と切り替え

編集用一覧・常時一覧・通常の構想メモ一覧からメモを開く入口を揃えた。同じメモを再選択しても入力を変えず、保存・反映・削除・切替確認中の重複操作は実行しない。

未保存なら「保存して切り替え／保存せず切り替え／キャンセル」を表示する。確認中は自動保存を保留する。保存失敗・競合・保存中の追加入力・反映先の未解決エラーがある場合は元の編集画面を維持する。原本保存済みで反映だけ失敗した場合を未保存として扱わず、エラーを表示する。バックアップだけの失敗は原本保存成功を取り消さない。

明示した破棄では共有文書を最後の保存済み内容へ戻す。未保存の新規メモも除き、破棄した内容が別のメモを保存する際に混ざらないようにする。編集から通常一覧へ戻る既存の破棄操作も同様に修正した。メモ切替後に遅れて届いた別作品の同期状態を適用しない。
