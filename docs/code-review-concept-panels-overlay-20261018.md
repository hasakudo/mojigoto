## 開閉ボタンの位置の訂正（同日）

利用者の意図は、一覧の開閉ボタンを参照パネルの上に維持し、展開した一覧の内容がノート参照に重なる配置だった。前回の「参照の見出しの下へ一覧を移す」変更を訂正する。

一覧は操作ヘッダー直下の従来位置へ戻す。ノート参照の上端は一覧のsummaryの下端＋10pxで固定し、展開した一覧全体の下端には追従させない。一覧を開いても両パネルを上下に配分せず、一覧内容をノート参照へ重ねる。ノート参照はボタンの下から画面下端までを使い、一覧の開閉で位置・高さを変えない。
