## 操作と範囲

原稿編集画面の歯車→「原稿内を検索・置換」。現在開いている1ファイルの本文だけを対象に、未保存入力も検索する。結果は行・文字位置と抜粋で表示し、押すと本文へ戻って一致文字を選択する。ファイル名、別ファイル、ノート、作品全体は対象にしない。

「置換する」をONにし、変更前後を見て「この箇所を置換」またはチェックした候補を置換できる。「全選択」はページ外も含む有効候補が対象。空の置換文字は削除、同文は候補外。文字列検索のみで、大小文字の区別は条件欄で変更できる。ノート版で確認済みのコンパクトな配置とガイドへの説明分離を再利用した。

ルビ・傍点内と不完全な記法のフィールドは検索・移動のみ。新しい記法の成立や保護境界の変化は操作全体を拒否。古い候補、別ファイル・作品・接続へ切り替えた後の候補を適用しない。保存・同期・IME変換中、競合時、読込表示で入力欄が無効な間は適用を抑止する。

置換は通常入力と同じく未保存になり、自動保存設定に従う。手動保存後も同じ編集セッションなら「直前の置換を戻す」を使える。ただし置換後に本文を追加入力・変更した場合は、追加入力を保護するため取り消しを拒否する。原稿は本文全体が1フィールドなので、ノートの別フィールド保持とは異なり本文の一部だけを推測して戻さない。置換を戻して保存済みの元本文と一致した場合は、通常入力と同様にdirty=falseになる。
