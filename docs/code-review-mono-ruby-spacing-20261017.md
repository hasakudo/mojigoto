# 隣接する単一ルビの重なり対策（2026-10-17）

## 結果と対象

利用者の実機例 `|人《レイ》|族《オン》|の《テール》|国《王国》` で、親文字1字に対して複数字の注釈が続くと重なるとの報告を受けた。縦書きプレビュー・簡易書き出し（通常／二面）・実寸優先の単一ルビで、注釈の長さに応じた領域を取り、親文字と注釈をそれぞれ中央に配置した。

プレビューの従来の短いルビ用の圧縮と、書き出しの負の末尾マージンを、単一ルビには適用しない。組版調整OFFでも重なり防止の領域は確保する。原稿の文字列・ルビ対応・文字数集計用displayWidthは変更しない。

## 変更

- `src/preview/ruby-spacing.js`：親文字が表示上1字のルビの占有長を共通計算。Intl.Segmenterの文字単位を用い、異体字セレクタ・結合文字を分断しない。占有長は `max(1, 注釈の文字数 × 0.55 + 0.1)em`。各経路で最大の注釈フォント0.55emと前後のすき間を確保する。長い注釈を省略・縮小・自動分配しない。
- `vertical-layout-core.js` と `vertical-print-line-utils.js`：初期行分割と再調整が単一ルビの同じ占有長を使用する。親文字1字分だけで詰め込まない。
- `server/vertical-dev.mjs`：単一専用の描画。親文字の送りとルビの送りを一致させ、領域の中央へ配置する。
- `merged-manuscript-browser-html.js` と `merged-manuscript-browser-realprint-html.js`：同じ占有長と中央配置。グループの既存CSSから単一だけを分離する。

今回の対象は隣接する単一ルビ。複数の親文字を持つグループルビの字送り・1組が行長を超える場合の配置、ページ／段の境界を含む長いルビ全体の改善が完了したとは扱わない。
