# 保存・同期の整理2-A5：作品設定の永続化処理（2026-10-27）

## 承認と範囲

利用者がメモの速度改善を一区切りにして、作品設定の保存整理へ戻ることを承認。既存の編集・保存動作を保ちながら、取得と保存の境界を専用モジュールへ移す。作品共通ノートなどの機能追加は今回行わない。

## 変更

app.mjsから以下の4関数をweb/lib/work-settings-persistence.mjsのcreateWorkSettingsPersistenceへ分離した。

- ensureWorkSettingsFile：既存のwork.json／singleWork.jsonの取得と必要時の初回作成
- loadWorkSettings：本文読込・正規化・編集状態と設定キャッシュ・表示と監視再開
- reloadWorkSettings：指定された最新版の再読込
- saveCurrentWorkSettings：手動／自動保存、保存済み基準・作品一覧・キャッシュ更新、保存待ちの追加入力保持、競合と失敗表示

4関数の処理本体は移動前と一致することを照合した。初期化時に保存タイマーと外部監視の宣言前に処理を実行しないよう、依存は遅延コールバックで接続する。既存のGoogle Driveの未許可ファイルを重複作成しない保護、work.json優先、OneDrive／Dropboxの初回作成を維持する。

フォーム描画・入力イベント・画面を開く際のキャッシュ選択と遷移・未保存時の移動判断・共有state・外部更新判定はapp側に残す。保存形式、既知／未知の設定項目、関連作品ID、書き出し設定の仕様は変更しない。通信失敗後の自動保存予約も既存挙動のままとし、今回新しい再試行仕様を導入しない。

ソース抜き出しに依存していたGoogle Drive設定ファイル権限テストは、実際の新モジュールを呼ぶ構成に更新。保存案内の検証も移動先を参照するよう更新し、検証を削除しない。
