## 利用する入口

ノート右側のプレビュー見出しに「別タブで開く」を追加した。リスト／ボードの現在の表示種別を別タブへ開く。全画面ボードの上部にも同じボタンを追加した。同じノート・同じ種別は既存タブを再利用する。タブはVS Codeの標準操作で左右のエディターグループへ移動できる。

別タブは表示専用。本文、項目のふりがな、本文ルビ・強調、関連件数、項目メモ、分類画像を表示する。リストの大分類、ボードのカード、項目メモは表示側で開閉できる。既存の編集画面内プレビュー・全画面ボードの操作は維持する。

## 内容と保存状態

表示タブがある間だけ編集画面からスナップショットを150ms間隔でまとめて送り、自動保存OFFでも未保存入力を表示する。ホスト側でも既存の保存予約メッセージから最新の入力を保持し、表示通知の待ち時間中に編集を終了した場合も最後に受信した下書きを表示する。

編集元は正規化したファイルパスとパネルで照合し、編集セッションID・連番で古い文書や古い通知を拒否する。表示側の準備完了後に最新内容を要求する。編集Webviewの再読込・編集再開では新しいセッションで再接続する。

表示側は保存・削除・移動・同期のハンドラーを持たない。編集から受け取るデータを正本へ書き戻さず、表示タブを閉じても保存や編集の終了は起こさない。最後の表示タブを閉じたら下書き通知を止める。画像の参照範囲は編集元の作品に固定し、表示先WebviewごとにURIを変換する。範囲外パスは除外する。
