# VS Codeノートインポートの項目メモ選択（2026-10-19）

構想メモ絞り込みとWebの候補・Loadingは利用者確認済み。章単位書き出しより先に、通常ノートインポートの項目メモ選択を改善する依頼に対応した。

## 選択とプレビュー

- 新規作成・全体置換は「項目メモも取り込む」、選択挿入は「項目メモも挿入する」を追加。既存の取り込み動作を保つ初期ON。読み込み元にメモがない場合は選択できず、その理由を示す。OFFでも詳細本文・項目は取り込む。
- 全体置換は大分類・項目・項目メモを丸ごと置き換える。OFFは元のメモを保持する意味ではないことを画面・既存の確認ダイアログ・ガイドに明記。元のメモを残す用途は項目上書きの本文のみへ案内する。
- 項目上書きはラジオで「詳細本文のみ（メモを保持）」（初期）／「詳細本文＋項目メモ」を選ぶ。読み込み元にメモがない場合は既存メモを消さず、本文のみを使う。
- 比較プレビューに詳細本文とメモの本文・形式・タグを左右表示し、保持／上書き対象を示す。新規・挿入のプレビューにも対象外を明示し、大分類挿入では内包するメモを表示する。選択を変えても元の読込データを変更しないため、ONへ戻せる。
- 読み込み元ファイルの「再読み込み」でもメモ選択を保持する。挿入／上書きのタブを切り替えてもそれぞれの選択を使う。既存の「次を選択」「閉じる」と対象候補の再描画は維持する。

## 保存と保護

- 共通のインポート用ヘルパーでメモの有無を反映する。新規・挿入では本文・形式・タグだけを取り込み、元の構想メモへのリンク・自動反映設定を引き継がない。除外は表示だけでなく保存データからも外す。
- 既存メモの上書きでは、本文・形式・タグと更新日時だけを変更する。対象項目のID・項目名・構想メモへのリンク・同期基準・自動反映設定などは保持する。今回のインポート処理が行うのはノート保存で、構想メモへ直接書き込まない。以降の通常保存・手動反映では既存の設定が引き続き適用される。
- 比較時の本文と、メモ込みの場合はメモ内容を実行直前と比較する。外部変更があれば上書きせず再読み込みを案内する。本文のみでは保持対象のメモに外部変更があっても、最新のメモをそのまま残す。保存直前の外部ファイル変更も既存のstorageRevision検証で止める。
- 選択インポートのタブ切替に、実行処理が初期モードを参照する箇所があった。受け取った操作の種類をホスト側で明示して、挿入／上書きを取り違えないよう修正した。
- WebのMarkdown読込、データ形式、Webの版番号は変更しない。今回の更新はVSIXのみ。
