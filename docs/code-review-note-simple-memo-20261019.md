# 新規インポートの生成競合と項目メモの簡単な記述（2026-10-19）

新規／置換、挿入／上書きは利用者確認済み。追加で報告された新規インポート時のWeb読込用Markdown警告と、項目の下へのメモ付き挿入・手入力の難しさに対応した。

## 新規作成と生成通知

- 新規インポートはcreateNewNoteで空のノートを保存し、saveNoteFileでもう一度保存していた。最初の保存が起動するMarkdown生成中に二度目の保存が入り、保存版不一致の警告が出る構造だった。
- createNewNoteにinitialGroupsのオプションを追加し、インポート内容を正規化して最初の保存へ含める。インポート側の二度目の保存を廃止。通常の新規作成やテンプレート作成の引数・動作は保つ。
- 通知文は「ノート本体はそのまま」から「Web読込用Markdownの更新が未完了（ノートの保存とは別の処理）」へ変更。実際の生成失敗時も原本保存の失敗と混同しない。

## 手入力の記述と項目の下への挿入

```markdown
### 項目名
項目詳細

#### 項目メモ
ここにメモ本文
```

- 手入力で上の簡単な記述を認識する。リスト形式は「#### 項目メモ（リスト）」。次の項目・区分・大分類までをメモ本文とし、末尾の区切り改行を除いて内部の空行は保持する。
- メモ中のコードブロック内の見出しは本文として保護する。メモ内の他の4段目見出しも本文として扱う。重複の項目メモや壊れた旧形式は警告し、内容を勝手に捨てない。
- 従来のmojigoto-item-memo-v1形式はそのまま使える。通常書き出しは形式・タグ・任意の見出しや改行を正確に保持する旧形式を維持し、簡易形式は読込用として追加する。専用Web読込用Markdownの本文は従来どおりメモ形式として解析しない。
- 「項目の下へ追加」は簡易形式・旧形式のどちらのメモも項目と一緒に挿入できる。メモが含まれる場合だけ「項目メモも挿入する／項目メモは挿入しない」を選ぶ。取消時は挿入しない。メモのないファイルでは追加選択を出さない。
- 挿入したメモの構想メモID・自動反映設定は引き継がず、既存項目・メモは変更しない。ここでの「項目の詳細を上書き」は従来どおりプレーンテキストの本文のみを扱う。
- 読込サンプル `docs/examples/note-items-with-memos.md` を追加し、VS Codeガイド・README・Webガイドも更新。
