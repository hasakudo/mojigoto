# 表示専用ノートプレビューの項目メモ一括開閉（2026-10-18）

優先2を実装。表示専用のプレビュー・ボード上部へ「メモを開く」「メモを閉じる」を追加し、そのタブにある項目メモを一括開閉する。本文のあるメモとタグだけのメモを対象とし、大分類・ボード項目・目次の開閉は変更しない。操作不要のボタンは無効にする。

初回は従来どおりメモを閉じる。個別の開閉も引き続き使用でき、内容の更新と再読み込み・再起動では既存の項目IDごとの開閉状態を維持する。追加された新しいメモは閉じて表示する。一括操作は表示状態だけを保存し、ノート本文・項目メモ本体や編集元の未保存状態を書き換えない。

## 実機確認

1. ノートから表示専用プレビューを別タブで開き、上部の「メモを開く」「メモを閉じる」で一括開閉する。タグだけのメモも開閉できること。
2. 一部を個別に閉じ、ノート本文を編集しても表示側の開閉状態が保たれること。
3. ボードの別タブでも同様に操作でき、ボード項目自体は閉じないこと。
4. 再読み込み・再起動後も前回のメモの開閉状態が戻り、新規メモは閉じて表示すること。

確認後は優先3「Webで編集位置へ移動してもノートプレビューを閉じない」へ進む。
