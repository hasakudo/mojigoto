# 5-B3 Dashboardの執筆メモ：一覧・編集操作と構想メモへのコピー（2026-10-22）

## 変更

利用者は執筆メモの参照先表示とジャンプを確認済み。今回は`stats-panel.js`の一覧・編集・コピー操作を`dashboard-writing-memo-actions.js`へ分離した。

- 作品一覧／作品別／現在ファイルへの切り替え、編集開始／取消、メモ一覧の再取得、原稿の執筆メモ装飾の切り替えを移動。
- 外部コマンドから執筆メモタブを開く際の状態初期化と、パネルを開いてから対象メモを通知する処理も移動。公開コントローラーの入口は従来どおり。
- 原稿パス・一覧スコープ・編集中メモID・選択作品・作品一覧への戻り先はホストが所有し、getter／setterを通じて最新の値を共有。状態を二重に保持したり、非同期操作前の値を固定したりしない。ジャンプ・保存処理がホスト側で行う状態更新とも同じ変数を参照する。
- 構想メモへのコピーは、現在作品／明示された戻り先作品／Singleの保存先決定、本文・抜粋の整形、既定タイトル、writingフォルダへの所属、出典、ID・日時・初期表示設定、先頭追加を維持。コピー元の執筆メモは変更しない。
- 構想メモの保存完了→更新通知→完了案内の順序、対象不明・空本文・各境界の失敗時の通知を維持。
- メッセージ分岐の順序、パネル管理・復元、集計、保存形式、参照先表示、HTML/CSS、Web配布コードは変更しない。
