## バックアップ設定

- `mojigoto.backupIntervalMinutes`：初期値を30から0へ変更。未設定の場合は自動OFF。30等を明示している設定は書き換えない。原稿・ノート・構想メモの呼出元と補助処理のフォールバックも0へ統一した。
- `mojigoto.backupMaxPerFile`：整数1～50、初期50。原稿1ファイル、ノート1ファイル、作品の構想メモ保存ファイルを単位に、保護されていない手動・自動・復元直前の履歴の合計へ適用する。
- 件数の初期値は既存の保持範囲を維持した。設定を変えるだけでは削除せず、次の新しいバックアップ作成時に索引の各ファイルを整理する。内容重複で作成を省略した場合も整理しない。保護された履歴は件数に含めず、自動履歴の90日の期限は維持する。
- 自動OFFでも手動作成と復元直前の退避は利用できる。保持1件の復元でも対象を読み込んでから直前の内容を退避し、その内容を残す。

案内板に対象・自動OFF・保持件数・保護・90日と「バックアップ設定を開く」ボタンを追加した。ボタンはVS Codeの設定を `mojigoto.backup` で絞り込む。ガイドの初期値・保持条件・アイコンの説明も更新した。

VS Codeの設定はWebの自動間隔・保持条件と別。バックアップの形式・保存先は共通であり、作成した側の条件が共有索引へ適用される。Webから作成すれば引き続き従来の50件条件になるため、今回のVS Code設定がWebの作成にも適用されるとは扱わない。
