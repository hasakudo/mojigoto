## 実装

- `web/lib/catalog-delta.mjs`：差分確認、初期基準作成、通常探索への復帰を独立。初回はtoken=latest→通常探索→そのチェックポイントからの差分再確認が変更なしの場合に限り、一覧と差分情報を対応付ける。古い一覧へ新しいトークンを後付けしない。
- `web/storage/onedrive-provider.mjs`：選択フォルダの`/drives/{drive}/items/{folder}/delta`だけを使う。全ページに変更がない場合だけ再利用。削除を含め1件でも変更があれば通常探索。URLはGraphの同一drive・同一itemのdeltaに限定し、Drive全体への範囲拡大はしない。8秒・10ページ・2,000件を上限とし、メタデータ本文は保持しない。
- `web/app.mjs`：利用者・ルート・保存済み一覧の一致を確認して差分情報を読む。一覧と追跡情報は同じlocalStorageレコードに保存する。取得ごとのローカル変数で差分情報を保持し、後続の集計保存も同じ取得世代の結果だけを使う。通常の編集保存から一覧キャッシュを更新する場合は追跡情報を落とす。旧schemaVersion2の一覧も先行表示できる。
- `web/lib/work-discovery.mjs`：設定・共有集計の本文取得やJSON解析の失敗を報告し、不完全な一覧を基準にしない。OneDriveの通常一覧も応答配列と項目IDを確認し、不正応答を空一覧として確定しない。
- `web/index.html`、`web/boot.js`、`web/sw.js`：反映用バージョンと新しいモジュールのシェル登録を更新。

変更あり、期限切れ410、未対応・権限不足、通信失敗、不正リンク、ページ循環、上限超過では通常取得へ戻る。失敗後は5分、400／403／404／405／501では24時間、確認を休止して同じ失敗の負担を抑える。休止情報は通常の一覧キャッシュに対応付けて保存されるため、その破棄や編集によるキャッシュ再保存などで失効する場合がある。
