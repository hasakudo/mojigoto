# 単一ルビの字間再調整と、新規挿入の操作短縮（2026-10-17）

## 受領した内容と結果

前回の単一ルビは重なり防止の領域に余白を取り過ぎ、利用者の一太郎の例と比べて文字間が開いた。新規ルビのたびに別パネルを開く操作も執筆の流れを止めるとの指摘を受けた。

- 単一ルビの追加余白を取り除き、各経路の単一ルビを本文の0.5倍へ揃えた。2字の注釈までは本文1字分、3字なら1.5字分を確保する。
- 新規挿入は既定の種類に従う。グループなら原稿へ `|東京《よみ》` を挿入し、「よみ」を選択する従来の直接入力へ戻した。単一ならVS Codeの小さな入力欄へ `とう/きょう` のように一度で指定する。
- 既存ルビ内のAlt+Rは編集パネルを開く。右クリック／コマンドパレットに「ルビを編集…」も追加し、任意の選択範囲からパネルへ進める。

新規挿入の既定は既存の `mojigoto.rubyDefaultMode`（初期値グループ）。原稿のルビ記法は変えない。

## 字送り

共通の占有長を `max(1, 注釈の表示文字数 × 0.5)em` へ変更。本文・注釈を領域の中央へ置く。プレビューの単一は0.48emから0.5em、簡易／実寸の単一は0.55emから0.5emへ揃えた。複数の親文字を持つグループは従来の描画のまま。

## 挿入と編集

新規グループは設定された半角／全角の縦棒で挿入し、複数選択でも全ての「よみ」を正しい挿入後の位置で選択する。新規単一は親文字の表示上の文字数と区切り数を照合し、自動分配しない。空欄はその字にルビを付けず、全欄空欄は受け付けない。漢字・当て字・英字はそのまま使う。ルビに `/` 自体を含める場合は編集パネルを使う旨を案内する。

入力途中の取消では原稿を変更しない。複数範囲の2件目で取り消しても1件目を先に書き込まない。全範囲の入力後に版と元文字列を照合して、1回の編集／Undo単位で適用する。単一入力中に原稿が変われば入力欄内で案内し、適用直前でも再確認する。閉鎖・編集失敗でも古い位置へ書き込まない。パネルの元原稿変更検出も従来どおり。

新規の複数範囲に既存ルビが混在する場合は全体を編集パネルで確認し、部分的に先行挿入しない。途中選択・異体字・結合文字・重複／重なる範囲の解釈は、挿入とパネルで共通化した。改行を含む範囲・未完のルビ記号は止める。

変更箇所：`src/editor/ruby-insert.js`、`ruby-edit-core.js`、`ruby-editor.js`、`ruby-editor-html.js`、`ruby-tools.js`、`package.json`、README、案内板。
