## 変更

- 見出しを短い「検索・置換」にし、対象ノート名は見出しのtitle属性へ保持。検索・置換入力のラベルは読み上げ用に残し、画面上はプレースホルダーとコンパクトな1行高の欄に整理。置換欄は複数行を入力でき、必要なら縦に広げられる。
- 対象フィールドと大小文字は初期折りたたみの「条件」へ集約。閉じていても「条件：名称・詳細」「条件：詳細」「条件：対象なし」等で現在の設定が分かる。条件の変更は既存どおり候補・選択を更新する。
- モーダル内の説明と項目メモの自動反映説明を専用ガイドへ移動。ガイドには対象範囲・名称の内訳・空文字削除・ページ外の全選択・ルビ等の保護・保存反映・取り消しの条件と履歴破棄を記載。独立guide.htmlとアプリ内ガイドの両方に追加した。
- モーダルの「ガイド」は同じ画面内のguideDialogへ該当項目を開く。閉じると元の検索モーダルに戻り、検索語・置換語・候補を保持する。他のガイド入口は従来の別ウィンドウ優先・ポップアップ不可時の内蔵表示を維持する。
- 選択・一括置換・取り消しとページ操作を共通フッターへ集約。「全候補を選択」は「全選択」へ短縮し、ページ外も含む意味はtitle属性とガイドで補う。候補内の選択と1箇所置換は同じ行にまとめる。
- 上下の余白を縮め、結果領域が残りの高さを使う。検索条件展開時や低い画面では上部・フッターの縦スクロールを許し、閉じるや操作が失われるのを防ぐ。置換・保存・競合防止・取り消しの意味は変えていない。
