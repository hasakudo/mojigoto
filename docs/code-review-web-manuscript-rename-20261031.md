## 実装

原稿一覧の各行に「名前変更」を追加。章フォルダは名前全体、原稿は入力欄に拡張子を含まない名前を表示し、右側に保持する拡張子を固定表示する。元の大文字小文字（.TXT／.MDを含む）も保持する。原稿ルート自身・作品フォルダは対象にせず、原稿一覧に表示する子フォルダ／原稿が対象。編集画面への追加入口は今回不要とし、一覧から操作できる形で要望を満たす。

- 名前の検証、空欄・禁止文字・予約名と同名重複の拒否。同名チェックは最新の親一覧で行う。
- 読込中に画面・利用者・作品・ルート・providerが変われば書込前に中止。外部で名前や所在が変わった場合も一覧の再読込を案内する。
- 変更中は保存中フラグとモーダルのcancel防止で二重送信・移動・閉鎖を抑制する。通信失敗では入力欄を残して再試行できる。
- 本文は再保存しない。OneDriveはeTag、Google Driveは既存の保存と同じv2の実ETagで条件付きメタデータ更新。OneDriveは既存メタデータ取得にもfolderを追加し、フォルダ種別を保持する。
- Dropboxは同じ親フォルダ内のmove_v2、autorename:falseで変更する。APIに条件付き改名の版指定はないため、本文保存と同等のETag保証は主張しない。移動はIDで対象を指定し、移動先を上書きしない。大文字・小文字だけの改名はAPIの制約として説明を表示し、一時名による複数段階の変更を自動では行わない。
- IDを維持し、一覧キャッシュを破棄。最近編集した原稿と作品／HOME履歴の名前・フォルダ階層を更新し、ピン留め・日時・別作品・ノートを保持する。全体プレビューは次に開く際の新しい目次取得で反映する。ブラウザの過去の履歴項目は書換えず、ファイルを開く際に既存のメタデータ再取得を使う。
- ガイドは折りたたみ項目に一文追加し、アプリ内と独立ページを同期した。

- closeで対象を消すのは、実際にダイアログが閉じている場合だけとした。
- 同じ親フォルダの参照再取得で対象外扱いにしないよう、作品・ルート・provider・セッションの照合に加えて親IDを比較する。
- パネルを開いた後に保存・同期・編集状態が変わった場合は、無反応にせずパネル内へ説明を表示する。
- 「閉じる」を通常ボタンとして独立させ、入力欄でEnterを押した際に閉じる側が既定送信になることを防止。送信元ボタン情報がないsubmitにも対応する。
