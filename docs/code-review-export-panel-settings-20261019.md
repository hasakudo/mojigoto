# 原稿書き出しの整理 1-B：設定保存を分離（2026-10-19）

## 変更

panelとexport-uiに分散していた書き出し設定の保存キー、判型・版組のキー補正、保存状態の読み書きを`src/export/merged-manuscript-panel-settings.js`へまとめた。VS Codeそのものには依存せず、呼び出し元のcontext経由でworkspaceStateへアクセスする。

次の二つの更新規則は別の処理として維持した。

- `updatePersistedPanelUiState`：画面操作中に受け取った通常／二面／判型別のマップをマージする。受け取っていないマップと、既存の追加属性を保持する。
- `writeMergedManuscriptBrowserPanelState`：書き出し時の現在の通常／二面と判型・段組の設定を確定する。他の版組と判型の値は保持するが、現在の設定項目は既定のフィールドに作り直す。トップレベルの任意属性は引き継がない。

両者を同じ保存処理へ一本化せず、関数本体をそのまま移した。共通の保存キー文字列は一か所とした。読み込み失敗の扱いも従来どおりで、書き出し側の読込はnullへ戻し、画面操作側では例外を呼び出し元に返す。

設定の値・初期値・保存形式・更新タイミング・画面操作側の保存→書き出しコールバックの順序を維持。HTML/CSS・画面スクリプト・CSP・章の対象・保存先・上書き・版面／ルビ計算は変更していない。
