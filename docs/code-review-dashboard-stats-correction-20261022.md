## 変更

SNS画像プレビューの内部スクロールは利用者確認済み。今回はDashboardの集計補正の操作受付を整理した。

- `stats-panel.js`の`handleStatsCorrection`と`offerCorrectionSheetsSync`を`dashboard-stats-correction-actions.js`へ移動。改行コードを除き関数本体が着手前と同じであることを確認。

- 補正完了→Dashboard再描画→成功案内→利用者が選んだ場合だけSheets送信、という処理順を維持。送信失敗は補正結果を戻さず警告する。
