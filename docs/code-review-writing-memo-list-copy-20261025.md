# 追加修正6：執筆メモ一覧から構想メモへ反映（2026-10-25）

## 変更

ごみ箱のカウントは利用者確認済み。合意順6として、執筆メモを編集で開かず一覧から保存済み内容を反映する入口を追加。

- ファイル別・作品別の執筆メモ一覧で、未処理／保留・完了・アーカイブの各カード下部に「構想メモへ反映」を表示する。ヘッダーの修復・編集操作を圧迫しないよう本文の下へ配置。
- 一覧ボタンは`savedOnly`を付け、ホストで指定された執筆メモ保存元を読み直す。メモIDが一意に見つかった場合だけ、その保存済み本文・抜粋・原稿パスを既存の反映処理へ渡す。古い一覧表示の本文や別の入力欄を使わない。
- 保存元が不明、対象が削除済み／重複ID、空本文、読込失敗の場合はコピーしない。現在作品の保存元へ勝手に切り替えて同IDの別メモを反映しない。
- 既存の編集中ボタンは入力中の本文を反映する動作を維持。編集中は一覧用ボタンを重複表示しない。保存後に編集が閉じる動作も維持。
- コピー先は保存元読込の前に確定し、その後に現在作品が変わっても反映先を変えない。作品別一覧では完了・アーカイブにも作品IDを渡し、現在のView作品へ誤反映しない。
- 更新／新規作成の選択、比較確認ON/OFF、取消、処理の直列化、対象変更・保存版の競合保護は`writing-memo-concept-copy.js`をそのまま再利用。元の執筆メモへの書込みは行わない。
- ボタンのクリックは伝播を止め、カードの原稿ジャンプを発火しない。版は1.0.68。インストール・公開・コミットは行わない。
