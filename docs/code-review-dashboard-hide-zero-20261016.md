# Dashboard「0件を隠す」の保持（2026-10-16）

実機追補：利用者から「ONを維持できるようになりました」と確認済み。次のテンプレート／Markdown読込へ進む。

## 確認した原因と範囲

利用者から、ONにしたチェックが再起動／再読み込み・作品切替・拡張更新のいずれかでOFFへ戻る報告を受領。従来も `vscode.setState()` に保存していたが、拡張側の永続保存はなく、Dashboardの復元処理はserializerへ渡された状態を読み取っていなかった。WebViewの再描画内での保持だけでは、パネルを作り直す経路を十分にカバーできない。利用者環境でどの操作が直接の契機だったかは未確定。

## 変更

「0件を隠す」だけを `context.globalState` の `mojigoto.stats.hideZeroGroups` にbooleanで保存する。このVS Codeの利用環境で共通の表示設定とし、作品データには書き込まない。キーに拡張のバージョンを含めず、更新後も同じ保存値を使う。

ホストの保存値をHTMLへ渡し、WebViewの古い状態より優先する。まだ永続値がない場合だけ、serializerの保存状態、または既存WebViewのON/OFFを引き継ぐ。明示したOFFも保存し、古いONで上書きしない。保存値も旧状態もなければ従来どおりOFF。

チェック変更は画面へ即時反映し、ホスト側の記憶も即時更新する。永続書き込みは順番に処理し、連打したON→OFFで順序が逆転しないようにした。HTML再生成中も最新の値を渡す。古い画面から遅れて届いた通知・不正値・遅れた初期化通知を採用しない。保存に失敗した場合は警告を表示する。他のDashboardのUI状態やハイライト検出条件は変更していない。
