# 通常ノートの項目メモ書き出し・読込（2026-10-18）

プレビューと他ノート参照は利用者確認済み。優先5へ進み、通常ノートの項目メモを出力・読み戻しに追加した。利用者の追加指定によりHTMLでは含める／含めないを選択する。Markdownはメモの読込まで今回実装し、メモを取り込むか選ぶUIは後続で検討する。

## 出力

- 単体HTML、プロット／資料まとめ、作品・ViewまとめのHTMLは、対象のノートにメモがある場合に「項目メモを含めない／含める」を選択する。取消時は書出ファイルを作成しない。メモのない場合に不要な選択を増やさない。直接のHTML描画APIの既定も従来どおり含めない。
- 含める場合はメモ本文・タグを本文と区別して表示し、ルビ・傍点の既存変換を共用する。HTML文字列はエスケープする。
- テキスト、CSV、Markdown、各まとめにもメモを含める。CSVは「項目メモ」「項目メモのタグ」列を追加する。作品設定のメモを出力する既存設定とは別の項目。
- 単体Markdownは従来の大分類・区分・項目の見出し構造を保つ。項目末尾の「項目メモ」と `mojigoto-item-memo-v1` のフェンスを使い、本文・形式・タグを区別する。メモ中の記号でフェンスが閉じない長さを選ぶ。メモ内の見出し・改行・空行を保持し、構想メモのID・同期日時等は出力しない。
- まとめMarkdownの見出し構成は従来どおり閲覧用。単体ノート用Markdownの新規・置換読込と混同しない。

## 読込

- VS Codeの新規／全体置換、項目追加、選択インポートの項目・大分類挿入でメモ本文・形式・タグを保持する。挿入時の項目IDは新規に作り、構想メモへのリンクと自動反映は持ち込まない。
- 「詳細本文のみ」の上書きは従来どおり本文だけを変更し、既存の項目メモを維持する。対象画面の説明も明示した。メモの選択的な上書き・除外は後続検討。
- 全体読込プレビューは「項目メモあり」を示し、展開するとメモ本文とタグを確認できる。選択挿入のプレビューにもメモを表示する。
- 形式を認識できない、または閉じていないメモブロックは警告し、元の文字列を本文として残す。通常のコードブロック内の形式見本はメモへ変換しない。
- Webと共用のパーサーのため、Webの通常Markdown読込も対応する。従来の専用Web読込用Markdownの仕様は維持し、その本文中の形式見本を誤変換しない。ガイドの通常Markdownの説明も更新した。

Web本体・boot 1.0.203／SW v248、styles.css 1.0.180。設定ファイルの変更は不要。VS Codeだけで使う場合はVSIXを更新し、Webで新形式を読み込む場合はWebも更新する。

## 実機確認

利用者はVS Codeのノート書き出しとWebの.md読込を確認済み。VS Codeインポート自体の実機確認は未確認。取込対象の選択UIは、新規／全体置換・挿入・詳細本文のみ上書きの扱いをまとめて後続で検討する。

1. ノートからHTMLを書き出し、「含める」「含めない」を選んだ出力を確認する。まとめHTMLでも同様に選べること。
2. 単体Markdownを書き出し、新規または全体置換のプレビューにメモが表示され、保存後も本文・形式・タグが戻ること。
3. 選択挿入で項目・大分類を追加し、メモも戻ること。詳細本文だけの上書きでは既存メモが変わらないこと。
4. Webを更新した場合は同じ通常Markdownを読み込み、メモが本文へ混ざらず戻ること。

確認後、メモを取り込むか選ぶUIの検討と、優先6の構想メモのノート項目順を扱う順番を決める。
