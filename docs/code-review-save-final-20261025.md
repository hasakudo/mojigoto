# 7-D 共通保存の競合・一時ファイルの最終点検（2026-10-25）

## 変更

バックアップの作成・一覧・保護・復元は利用者確認済み。共通保存と残るバックアップの更新経路を最終点検した。追加分割は行わず、既存の共有処理を維持する。

- 原稿バックアップの旧保存先からの移行とパス移行では、最初に読んだ索引の版を保持し、更新時にもその版で照合する。スナップショットのパス移行も読込時の版で照合する。
- 原稿／ノート／構想メモの保護変更でも、読込時のスナップショットの版を引き継ぐ。書込直前の再読込を基準にして外部変更を取り込んだ扱いにする経路を修正。
- 原稿の旧索引読込は、未作成・JSON構文エラーの従来の回復経路を保ちつつ、I/Oエラーまで空の履歴として扱う動作を修正。失敗を呼出元へ返して更新を止める。
- 共通保存の一時ファイルは排他的にopenし、書込後にハンドルを閉じてから置換する。作成に成功して所有したファイルだけを後始末する。作成失敗時に同名で存在していた一時ファイルを削除しない。
- ファイル単位の直列化、元ファイルへの再照合、置換失敗時の元データ保持、返り値、保存書式、バックアップ保持・復元・自動反映の規則は維持。
- ファイル群全体のトランザクションや別プロセスのロックを追加する変更ではない。移行途中の個別ファイル書込が完了してから競合で中断することはあり、完了済みの書込を巻き戻さない。
- Webは未変更。版は1.0.68。インストール・公開・コミットは行わない。
