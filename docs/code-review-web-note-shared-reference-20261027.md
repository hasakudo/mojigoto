## 操作と動作

ノート編集画面の「プレビュー」→「参照元作品」で関連作品を選び、プロット／資料とノートを選択する。VS Codeの既存の保存済み関連設定、同じクラウド・作品ルート、Google Driveの追加許可という条件は原稿画面と同じ。

自作品の「編集中」では未保存のノートを従来どおり表示し、項目から編集位置へ移動できる。関連作品では読み取り専用と明示し、他作品の項目から編集中のノートへジャンプしない。関連作品で「編集中」を選ぶことはできず、自作品へ戻すと未保存の下書きへ戻る。編集中の作品・ノート・保存先・dirtyは変更しない。編集や保存に伴うプレビュー更新でも参照元と表示位置を保つ。
