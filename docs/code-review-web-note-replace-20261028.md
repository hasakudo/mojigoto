## 操作

ノート編集画面の歯車→「ノート内を検索・置換」から「置換する」をONにする。初期は検索のみ。検索語、置換後の文字、名称／項目詳細／任意の項目メモ、大小文字を指定し、候補の変更後と場所を確認する。空の置換語は削除、同文は変更なしとして候補から除外。ルビ・傍点内、不完全な記法のフィールドは検索・移動だけ可能で、置換の選択・実行ボタンを出さない。

「この箇所を置換」で1件、チェックした候補を「選択したN箇所を置換」で一操作として適用。「全候補を選択」はページ外も含む有効候補が対象で、初期選択は0件。空白・改行・空文字も変更後表示で区別する。適用後は件数と「直前の置換を戻す」を表示する。

対象は編集中の1ノート（プロット／資料）だけ。未保存入力も扱い、タグ・ふりがな・リンクID・同期情報は変更しない。項目メモは更新時刻を通常入力と同じ意味で更新し、保存時に既存の自動反映設定へ従う旨を表示する。

## 保存・取り消しの境界

- 候補生成時の編集世代・ノートID・全体の文字列スナップショットを適用直前に照合し、共有セッションでもフィールドID・元文字列を確認する。入力、条件変更、再描画、保存後のデータ更新は候補と選択を無効化する。古い候補を一部だけ適用しない。
- 保存・同期・項目メモ反映・IME変換中、外部競合がある場合は置換／戻すを抑止する。保存状態変更時は操作ボタンも更新する。記法を新しく成立させたりルビ保護境界を変える置換は共有コアで操作全体を拒否する。
- 変更はライブのノートデータへ適用し、1操作につきmarkNoteDirtyを1回呼ぶ。編集欄・目次・プレビューを再描画する。クラウドへ直接保存する新経路は追加せず、既存の自動／手動保存、eTag競合保護、バックアップ、自動反映を使う。
- 戻す履歴はフィールドごとの変更前／変更後とIDを1操作分だけ保持。同じ編集セッション内なら通常保存後も戻せる。戻す際は対象が変更後のままか照合し、不一致なら全体を戻さず通知する。別フィールドへの追加入力や保存で更新された同期情報を保持する。
- 次の置換で履歴を更新し、別ノート・接続・作品への移動、ノートの再読込・外部更新反映・バックアップ復元では破棄する。検索条件と置換語は同じ編集セッションのメモリ内のみで、永続化しない。Ctrl+Zは横取りしない。
