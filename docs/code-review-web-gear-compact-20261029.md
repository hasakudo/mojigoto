# 歯車メニューのアイコン行と高さ調整（2026-10-29）

## 変更

利用者の要望に合わせ、既存5画面の歯車メニューを、上段の横一列のアイコン操作と、その下の文字ボタン・設定へ整理した。Web1.0.259／シェルv304／CSS1.0.201。拡張機能は変更なし。本番・テスト環境は未反映、コミット未実施。

| 画面 | 上段のアイコン（左から） |
| --- | --- |
| 原稿 | 接続、検索・置換、入力補助、ノート参照、バックアップ |
| ノート | 接続、検索・置換、入力補助、バックアップ |
| 構想メモ編集 | 接続、入力補助 |
| 構想メモ一覧 | 全メモ検索・置換、全メモバックアップ |
| 作品設定 | 接続 |

削除・自動保存・自動反映・数え方・各ガイドは文字を維持する。削除は従来の文言と色のまま。アイコンは44px角で、title、aria-label、読み上げ用の名称を付けた。既存のID、入力補助と参照の展開状態、ダイアログの関連付けを維持し、各アイコン操作後に歯車メニューを閉じる。保存ガイド（アプリ内・単独ページ）へアイコンの意味を追記した。

構想メモ一覧は、前回保留した状態表示と保存ボタンの高さも歯車とそろえた。PCは34px、小さい画面は既存の歯車に合わせ38pxで統一する。

## 検証

既存のメニュー、バックアップ、ガイド、入力補助、ノート／原稿／構想の検索、同期通知、ポップアップ位置の関連154テスト成功。バックアップ入口の既存テストは、直接の可視文字からアイコンの操作名を確認する形へ更新した。今回は見た目と入口の変更であり、新規テストは追加していない。

実クラウドへ接続しない仮データのブラウザで次を確認した。

- 390×660pxの原稿メニューは同条件の変更前441px→変更後285px。5アイコンは44px角で一列、横方向のはみ出しなし。
- ノートは4アイコンを幅220pxのメニュー内に表示。高さ285px、clientWidth／scrollWidthとも218px。
- 構想メモ一覧の状態表示・保存・歯車は実操作で未保存にした状態でもすべて38px。検索とバックアップの2アイコンが横並び。
- 構想メモ編集は2アイコン、高さ242px、横方向のはみ出しなし。作品設定の接続アイコンから設定を開ける。
- アイコンから入力補助・原稿検索・ノート検索を開き、メニューが閉じることを確認。Tabで接続→ノート検索へ移動し、Enterで検索ダイアログを開ける。
- PCのブラウザエラー0件。狭幅検証のiframe親タブには既存同様のMutationObserver.observeのNode型エラーが遷移ごとに発生（記録2件）。発生元は未特定だが上記操作と寸法は確認できた。実クラウド上の操作は未実施。
