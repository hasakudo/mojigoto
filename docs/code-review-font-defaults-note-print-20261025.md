# 共通フォント・ノートHTML印刷（2026-10-25）

## 現状と変更

原稿のフォントは各原稿フォルダの `.mojigoto.json` の `font.family` に保存され、全作品共通の指定がなかった。ノートHTMLは `.noteEntry` 全体（項目名・詳細・項目メモ）を `break-inside: avoid` にしており、残りの面積に入る詳細まで次ページへ移動する。一方、区分には後続を伴う改ページ制御がなかった。

- `mojigoto.defaultManuscriptFontFamily` を application スコープで追加。全作品の既定値を共通化する。文字サイズは既存の作品別設定のまま。
- プレビュー設定の「共通の既定フォントを使う」で継承と個別指定を切り替える。継承時は `font.useDefault: true` を保存し、共通フォント名を作品側へ固定しない。既存の `font.family` のみの設定は個別指定として維持する。サイズだけの保存では継承を解除しない。
- 起動時は環境変数で共通値をサーバーへ渡し、起動中は設定変更通知と既存の設定APIで更新する。共通値だけの通知では作品設定ファイルを書かない。
- `src/preview/font-defaults.js` で既定値・継承・CSS出力を共通化。フォント候補一覧を一つのフォント名として引用していた通常／実寸／Word用HTMLを修正し、CSS宣言やstyle要素を抜ける文字列を拒否する。
- `src/export/note-print-style.js` を単体・種類別まとめ・作品まとめのHTMLへ同じ順で適用する。区分・区分名・項目名・メモ見出しは後続との改ページを避け、詳細・メモ・長い補足は分割可能にする。画面の装飾とまとめ単位の明示的な改ページは維持する。
