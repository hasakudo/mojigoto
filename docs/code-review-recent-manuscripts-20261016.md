## 保存の記録と表示

原稿一覧のパンくずの下へ、折りたためる「最近編集した原稿」を追加した。このブラウザからWebで内容を変更して保存できた原稿を、保存日時の新しい順に最大5件表示する。ファイル名・章フォルダの場所・保存日時を示す。広い画面は2列、600px以下は1列。原稿直下・章フォルダのどちらからでも同じ作品の履歴を使う。

閲覧だけ、内容変更なしの保存、通信失敗・競合は保存履歴の追加／繰上げにしない。手動保存・自動保存の成功を対象にし、保存中に追加入力があっても実際に保存した版の記録を残す。Webの通常の「最近開いた画面」とは分けている。

履歴は利用者・クラウド・ルート・作品の単位でブラウザへ保存する。保存するのは項目ID・名前・階層・日時等の参照情報のみで、原稿本文や認証情報は含めない。履歴保存の失敗で原稿保存を失敗扱いにしない。更新前の閲覧履歴やVS Code・別ブラウザでの編集から自動的に過去5件を集める機能は含めず、更新後のWeb保存から記録することを画面と実機手順で説明する。

## 深い章への移動

履歴からファイルと章フォルダの最新情報を並行して確認し、本文を1回読んで既存の原稿編集画面へ渡す。ファイル・章の単純な改名を反映し、原稿の場所が変わっていたり、削除・未許可で確認できなければ、現在の入力と階層を変えず一覧内へ理由を残す。読み込み中の追加入力・別画面の読み込み・作品変更・保存中に古い結果を適用しない。

原稿を開いた後の「← 一覧」では、その原稿の章フォルダの一覧を表示する。履歴を開いただけでは保存順と日時を変更せず、名前・階層の表示情報だけ更新する。×は履歴から外す操作で原稿ファイルを削除しない。Webからのファイル移動・削除が成功した際は、古い場所の履歴を外す。
