# 接続後に全画面の読み込み表示が再出現する経路の修正（2026-10-29）

利用者がガイドの見やすさを確認。全体プレビューの前に、ログイン後にHOMEが表示され、クラウド接続・自動接続後の作品一覧取得で再び操作を遮る読み込み表示が出る問題を報告。

showInitialViewRestoreLoadingは履歴に前回の編集画面が残っていればauthBootを再表示しており、loadWorksからも呼ばれる。認証やログイン表示の終了時に一度authBootが隠れていても、その後の作品一覧取得でview-restoreの全画面表示へ戻れる経路を確認した。

この関数を、すでに表示中の起動カバーの継続だけに限定。authBootが非表示なら再表示しない。起動直後から続いている前回画面の復元待ちは維持し、HOMEが使える状態になった後は既存の作品一覧内のworksLoadingStatusで取得状況を示す。認証リダイレクトを自ら開始した際の認証表示や、各画面内の読込表示は従来の処理を使う。

Web1.0.262／シェルv307。CSS1.0.202とガイドCSS・JS1.0.261は維持。クラウドAPI、保存、認証、作品発見・キャッシュの処理は変更なし。本番・テスト環境への反映とコミットは未実施。

## 検証

回帰テスト3件を追加し、全1,785件成功、接続・一覧速度・履歴を含む対象41件成功。HOME表示後に前回ルートが残る条件、起動直後の表示中カバーの維持、作品一覧ルート／履歴初期化後の表示終了を確認。

仮データのブラウザで前回ルートを残し、HOME表示後に実際のloadWorksを起動して一覧取得を待機させた。authBoot.hidden=true／view-restoreなし、一覧内の読み込み表示あり。その間にHOMEの接続設定を開けた。取得を再開すると3作品の一覧が完了。390px幅でも同じくカバーなし・一覧内の状況表示を確認。実クラウドへの接続・書込はしていないため、手動接続と自動接続の実環境でのタイミング確認は利用者確認に残す。
