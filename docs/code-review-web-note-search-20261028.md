## 操作

プロット／資料のノート編集画面の歯車から「ノート内を検索」を開く。名称（大分類名・区分名・補足・項目名）と項目詳細が初期ON、項目メモは初期OFFで追加可能。未保存入力も対象。ノート名・ふりがな・タグ・リンク表示名・ID・同期情報、関連作品の参照のみのノートは対象にしない。文字列検索のみで、大文字・小文字の区別は任意。

一致数と大分類／項目／フィールド／行・文字位置、短い抜粋と強調を表示。ルビ・傍点内と不完全な記法のフィールドも検索一致に含め、その状態を表示する。結果の場所を押すとモーダルを閉じ、閉じた詳細／項目メモを開いて該当文字を選択する。検索時のデータとDOMの文字列が違う場合は移動せず再計算する。

結果は30件ずつページ表示する。検索条件は同じノートの編集セッション内で保持し、開き直すと最新入力で検索する。接続／作品／ノート変更と編集画面からの移動では条件・結果を破棄する。localStorageへ検索語や結果を保存しない。検索画面には置換ボタンを設けず、A2の実装に分ける。

## 実装境界

- web/lib/note-search-replace.jsにbuildSearchPlanを追加し、既存候補計算の一致範囲・Unicode位置・ルビ保護判定を利用。置換語は空文字に固定して検索を計算するため、検索語と置換語が同文の場合の候補除外で一致を失わない。置換候補APIの既存動作は変更していない。
- web/lib/note-search-controller.mjsを新設。NodeのCommonJSとブラウザの既存UMD公開をESMから読み分ける。Web固有の検索条件、モーダル、ページング、最新IDから入力欄を解決するジャンプを担当する。保存・dirty更新・同期のAPIは渡さない。
- app.mjsは編集メニュー・DOM参照、初期化、入力・再描画・画面変更時の無効化に接続。検索入力は160msの待ち合わせとIME中の計算抑止を行い、入力直後は旧結果を破棄する。
- データ変更時に結果を無効化し、移動直前にもノート・接続・作品・scope・JSONスナップショット・元文字列・DOM値を照合。次フレームのフォーカス前にも対象を確認する。結果の抜粋はtextContentとテキストノードで構築し、ノート内容をHTMLとして扱わない。
- 閉じる／検索条件とページ移動は結果のスクロール領域の外。狭幅では説明を短くし、結果領域を確保。画面が極端に低い場合は検索条件領域も縦スクロール可能。
- Service Workerに共有コアと新コントローラーを追加した。
