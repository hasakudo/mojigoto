3. 必要な修正と関係する検証を行う。保存・同期では通信失敗、外部更新、端末切替を含める。
4. 結果、未確認の構成、残る問題を記録し、元に戻せる単位で変更を残す。

最初の作業単位は「基準の記録と失敗6件の切り分け」。次に原稿の保存・競合を扱い、その後ノート・構想メモ、バックアップへ進む。全画面の一括分割は初回の対象にしない。
