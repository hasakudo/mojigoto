# 追加修正7-A・7-B：ノートの検索・置換え（2026-10-25）

## 変更

利用者が[初回実装案](note-search-replace-design-20261025.md)と進め方を承認。7-Aの候補計算・検証後、画面から使える7-Bの操作まで続けて実装した。

- `web/lib/note-search-replace.js`に、DOM・VS Code・保存処理に依存しない候補計算と選択箇所の変更前後計算を追加。Webへの将来展開も考慮した配置だが、Web画面への組込みは行わない。
- 名称（大分類名・区分名・補足・項目名）と詳細は初期ON、項目メモ本文は初期OFFで選択可能。ノート名・ふりがな・タグ・ID・リンク・同期情報などは対象外。
- 大小文字を区別しない初期値とし、区別するチェックも追加。元文字列のUTF-16位置と表示用の行・文字位置を保持。Unicodeの小文字化で長さが変わる文字とサロゲートペアを分断しない。
- 明示／暗黙ルビ・モノルビ列・傍点を全体として保護。不完全な記法のあるフィールドも保護し、一致箇所と理由を表示する。選択箇所の計算後も保護範囲を比較し、新しい記法や既存ルビの親文字範囲が生じる変更を拒否する。
- `search-replace-session.js`で適用直前のノートID・編集リビジョン・対象ID・元文字列を照合し、全箇所を検証してから変更する。項目メモは通常編集と同じく更新時刻だけを更新し、リンク・指紋を直接初期化しない。
- 1操作ごとに既存の`markDirty`を1回呼び、通常の未保存・自動保存・手動保存・同期・出典表示更新へ接続。画面のリスト・ボード・目次・表示専用タブも既存経路で更新する。
- ノート検索パネルに初期は閉じた「置換」を追加。候補の場所・変更前後、保護対象を20件ずつ表示する。場所から編集欄へ移動し、閉じた項目メモも開いて一致範囲を選択する。
- 1箇所ずつ、またはチェックした候補を置換。全候補の選択は明示操作とし、初期は未選択。毎回の確認モーダルは追加しない。置換文字は改行を含められ、空欄は削除として扱う。
- 専用の「直前の置換を戻す」は1操作分の文字列差分を保持。後から対象を編集していたら戻さず、無関係な入力や保存後の同期メタデータは保持。元に戻した内容も通常の保存経路へ乗せる。再読込では取り消し情報を破棄する。
- 入力・検索条件変更・Escape／ボード側からの検索解除で候補を無効化し、再計算する。IME変換中は操作を抑止。候補を古い条件のまま適用しない。
- パネル内でスクロールし、狭幅で入力補助やフッターと重ならない既存の作業領域を使う。ガイドに対象・保護・保存・取り消しの説明を追加。
- 版は1.0.68。インストール・公開・コミットは行わない。
