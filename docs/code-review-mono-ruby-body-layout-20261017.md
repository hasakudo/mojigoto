# 単一ルビの改行を本文に合わせる（2026-10-17）

## 結果

利用者の `|人《レイ》|族《オン》|の《テール》|国《王国》。` は、残り3字の行で「人族｜の国。」となっていた。前回は「テール」の注釈幅を本文1.5字分として行分割にも使用していたためで、句点が主因ではない。

今回は「できるだけルビに影響されない表示」という要望に合わせ、単一ルビの本文を1字として改行する。「人族の｜国。」を保ち、注釈の重なり防止は行確定後の表示処理へ分けた。縦書きプレビュー・簡易通常／二面・実寸優先が対象。原稿の記法、読みの内容、新規挿入・編集の操作は変更しない。

## 配置

- 単一ルビの本文送りと行分割上の長さは1字。組版調整ON/OFFとも同じで、句読点・閉じ括弧の処理はルビのない本文と合わせる。
- 行内で連続する単一ルビをまとめ、通常は本文の半分の大きさで注釈を配置。前後の空きへ最大半字分はみ出して位置を調整し、各注釈の中心も対象の親文字から半字以上離さない。
- 通常文字・グループルビ・傍点・改行で連続を区切る。隣にグループや傍点があれば、その側へ空きを借りない。
- 1つの注釈の長さは最大2字分の表示領域へ収める。極端に長い1件はその読みだけ先に縮小し、ほかの短い注釈の大きさを保つ。複数の長い注釈が密集して入らない場合は、位置の制約を満たすサイズへルビ側を追加縮小する。本文の字間・改行は広げない。
- 最終的な行・ページ・段が決まった後に計算するため、次の行の注釈と一緒に配置せず、原稿データや元のトークンは変更しない。

長い注釈を読みやすい大きさで常に表示しながら、本文位置も完全固定することは両立しない。今回の単一は本文を優先し、必要な場合に注釈を小さくする。利用者例の3字行では縮小せず0.5emのまま配置できた。極端に長い／密集した注釈は小さくなるため、実機・出力時に読みやすさも確認する。複数の親文字を持つグループルビの既存の扱いは今回変更していない。
