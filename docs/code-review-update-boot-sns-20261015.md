Webは本体のESモジュールより前に独立したboot.jsを実行し、Service Workerの更新確認を開始する。起動前のスクリプト読込失敗または20秒の待ち時間超過では、同じ版・同じセッションで一度だけ自動再試行する。更新待ちは最大4秒、静的取得は10秒で打ち切り、キャッシュがあれば利用する。再試行後も失敗する場合と本体開始後の起動失敗には、案内と再読込ボタンを残す。編集中・保存中・同期中の再読込は本体が拒否する。更新workerの有効化だけで編集中の画面を強制再読込しない。

SWの更新用スクリプト取得とアプリ本体のキャッシュは別なので、updateViaCache:noneだけに依存しない。インストール時の静的取得はcache:reload、動作中はcache:no-store、ApacheのHTML／JS／CSS等は再検証する指定にした。必須のJS／CSSの取得に失敗した版は有効化しない。API・config.jsonはSWの対象外とし、作品・認証情報・ローカル保存設定を削除しない。仕様確認：[MDN register](https://developer.mozilla.org/en-US/docs/Web/API/ServiceWorkerContainer/register)、[MDN Request.cache](https://developer.mozilla.org/en-US/docs/Web/API/Request/cache)。
