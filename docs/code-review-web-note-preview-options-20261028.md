# ノートプレビューの参照元・表示設定を折りたたむ（2026-10-28）

利用者の実機画像では、上部の切替・読み込み案内・説明がプレビューの大きな部分を占め、本文の可視領域が狭かった。切替や説明を折りたためるようにして本文を広く読む要望へ対応。

## 変更

ノートプレビューの参照元作品／種類／ノートの切替、状態案内、操作説明を「参照元・表示設定」のdetailsにまとめ、初期状態を閉じた状態にした。ネイティブのsummaryでマウス・タップ・キーボードから開閉できる。原稿側のノート参照パネルは今回の対象外。

折りたたみ中も、現在作品または関連作品名、参照のみであること、種類を要約表示する。関連作品候補の読み込み中バッジも閉じた要約欄に表示する。展開中は設定内の従来バッジと案内を表示し、要約欄の重複バッジを隠す。確認事項がある場合は要約に「確認事項あり」を添え、展開すると既存の詳しい案内を確認できる。長い要約は1行に収め、全内容はtitleにも設定する。

展開状態でも設定欄の高さをプレビューの55%までに制限し、必要なら設定内をスクロールして本文の領域を残す。要約は設定内のスクロールで追従する。プレビュー本文や選択の再描画でdetails自体を作り直さないため、編集・保存に伴う更新でも開閉状態を保つ。ブラウザの再読み込みをまたぐ開閉設定の永続化は追加していない。

現在作品の未保存プレビューと項目ジャンプ、関連作品の読み取り表示、読み込みの所有状態・要求順の保護を維持。内蔵／独立ガイドへ開閉操作を追記。通信・保存処理は変更していない。
