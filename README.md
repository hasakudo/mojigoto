# もじごと

VS Codeで小説や長文を書くための執筆補助拡張です。
原稿・プロット・資料・メモをまとめて管理し、縦書きでの確認から進捗の記録、書き出しまで行えます。

[もじごと HOW TO](https://mojigoto.com/) · [もじごと Web](https://web.mojigoto.com/about/) · [更新履歴](CHANGELOG.md)

![もじごと preview](images/preview-main.png)

## 主な機能

- **作品管理**：単一・複数作品の管理、原稿や章の並べ替え・移動、他作品からのノートコピー
- **縦書きプレビュー**：カーソルへの追従、書体・文字サイズ・行間・体裁の調整
- **ノートとメモ**：プロット・資料、構想メモ、執筆メモ、人物の呼び名一覧
- **執筆補助**：ルビ・傍点・字下げ、検索・置換、ハイライト分析
- **記録と保護**：文字数・進捗の集計、SNS向け進捗画像、バックアップ履歴の比較・復元
- **書き出し**：原稿・ノート・作品設定をTXT・Markdown・HTMLなどへ出力
- **Webとの併用**：クラウド上の同じ作品をスマートフォンやブラウザから編集

## 動作環境

- VS Code 1.80以上
- 原稿ファイル：`.txt` / `.md`
- 縦書きプレビューを使う場合：Node.js 18以上

縦書きプレビュー以外の機能は、Node.jsなしでも利用できます。

## インストール

VS Codeの拡張機能ビューで「もじごと」を検索し、Publisherが「葉さく堂」（ID：`hasakudo`）の拡張機能をインストールしてください。

## はじめかた

1. 小説用のフォルダをVS Codeで開く。空のフォルダでも構いません。
2. サイドバーの「もじごと」から、案内に従って初回セットアップを行う。
3. 作品ツリーから原稿やノートを開いて書き始める。

詳しい操作は、拡張内の **「もじごと:もじごとガイドを開く」** または [HOW TOサイト](https://mojigoto.com/)で確認できます。

### Single / Multi モード

| モード | 使い方 |
| --- | --- |
| Single | 1つの作品を管理します。シンプルに始めたい場合に向いています。 |
| Multi | 複数作品を切り替え、作品ごとに原稿・設定・ノートを管理します。 |

Multiでは選択中の作品が各機能の対象になります。他作品から設定やノートをコピーしたり、関連作品として結び付けたりできます。

## 作品ツリー

原稿・章フォルダ・ノートの作成、名前変更、移動、作品切り替えなどをまとめて操作できます。原稿構成エディタでは、入れ子の章の並べ替えや複数原稿の一括移動にも対応します。

![作品ツリー](images/work-tree.png)

## 縦書きプレビュー

編集中の原稿を縦書きで確認できます。カーソル位置への追従、章ごとの表示、句読点の体裁調整に対応。フォントは全作品共通でも、作品ごとでも指定できます。

![縦書きプレビュー](images/preview-ui.gif)

## ノートとメモ

| 機能 | 用途 |
| --- | --- |
| プロット・資料ノート | 大分類・区分・項目で整理。目次、検索・置換、関連ノートの参照、項目名のふりがなに対応。 |
| 構想メモ | アイデア・リスト・TODOを保存。項目メモとの双方向反映や、関連ノートでの絞り込みができます。 |
| 執筆メモ | 原稿の選択箇所に、推敲や確認のためのメモを残せます。 |
| 呼び名一覧 | 登場人物の一人称や相互の呼び方を表で管理。原稿から直接開くこともできます。 |

ノートはリストやボードで見渡せ、表示専用の別タブでも確認できます。テンプレートの再利用や、項目メモを含むMarkdownの読み込み・書き出しにも対応しています。

![ノート](images/note.png)

## Dashboard

文字数・目標達成率・締切・日別の執筆記録を確認できます。日別・月間・年間の進捗をSNS向け画像と投稿文にまとめ、保存・コピーすることもできます。

執筆記録をGoogleスプレッドシートへ送る **Google Sheets連携** も利用できます。任意機能で、導入手順は拡張内ガイドに掲載しています。

![Dashboard](images/dashboard.png)

## バックアップ

原稿・プロット／資料ノート・構想メモの履歴を自動または手動で保存し、比較・復元・保護できます。

作品設定・呼び名一覧・画像などは履歴の対象外です。作品全体の保全には、作品フォルダのコピーやクラウドの履歴も併用してください。

## 書き出し

- **原稿**：TXT・Markdown・Word用HTML・横書き／縦書きHTML。全体をまとめるほか、章ごとの別ファイルにも書き出せます。
- **作品設定・プロット・資料**：TXT・Markdown・CSV・HTML。ノートは項目メモも含められます。
- **印刷**：原稿HTMLの紙面プレビューで体裁を確認し、ブラウザから印刷・PDF保存できます。

書き出し先は設定の `Export Root` で指定します。作品ツリーの「倉庫」から、書き出したファイルを開けます。

![書き出しメニュー](images/export-menu.png)

## 入力補助

ルビ・傍点・括弧・三点リーダ・ダッシュ・見出し・字下げを、右クリックメニューやショートカットから入力できます。ルビはグループルビと、文字ごとに読みを付けるモノルビに対応します。

ハイライト分析では、見出しの一覧や表記を確認し、全角字下げをまとめて付与できます。原稿フォルダや章を指定した検索・置換も利用できます。

## もじごと Web

OneDrive・Google Drive・Dropboxに保存した作品を、スマートフォンやブラウザから閲覧・編集できます。原稿の全体プレビュー、ノート参照、検索・置換、バックアップにも対応します。

VS Codeと併用する場合は同じ作品フォルダをクラウド同期し、端末を切り替える前に保存と同期の完了を確認してください。Google Driveでは、Webで使うファイルや子フォルダへのアクセス許可が必要です。

利用条件・提供状況・始め方は [もじごと Webについて](https://web.mojigoto.com/about/)をご確認ください。

## 既定ショートカットキー

| キー | 機能 |
| --- | --- |
| `Ctrl + Alt + V` | 縦書きプレビューを開く |
| `Ctrl + Alt + N`（Mac：`Command + Alt + N`） | 呼び名一覧を開く |
| `Alt + R` | ルビを挿入・編集 |
| `Alt + Shift + R` | グループ／モノルビを切り替えて挿入・編集 |
| `Alt + B` | 傍点を挿入 |
| `Alt + M` | 執筆メモを追加 |

その他の操作は拡張内ガイドを参照してください。キーの変更はVS Codeの「キーボードショートカット」から行えます。

## 注意事項

もじごとは `.txt` / `.md` を扱うため、小説以外のプロジェクトでも動作する場合があります。小説用のVS Codeプロファイルを分けて使うことをおすすめします。
